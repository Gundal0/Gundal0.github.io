> 📖 **스토리** — 주문 상태를 문자열 `"paid"`, `"shiped"` 로 관리하다가 오타 하나 때문에 배송이 누락됐다. 페리스가 말했다. "가능한 상태를 타입으로 몽땅 적어. 그러면 컴파일러가 빠진 경우를 찾아줄 거야."

## 🧩 문제 1 — 문자열 상태값은 오타에 취약하다

## 💡 해결 1 — 데이터를 품은 열거형(enum)

```rust
#[derive(Debug)]
enum OrderStatus {
    Pending,                                  // 데이터 없음
    Paid { amount: u32 },                     // 구조체형
    Shipped(String),                          // 튜플형: 운송장 번호
    Cancelled { reason: String, refund: bool },
}

impl OrderStatus {
    fn describe(&self) -> String {
        match self {
            OrderStatus::Pending => "결제 대기".to_string(),
            OrderStatus::Paid { amount } => format!("{amount}원 결제 완료"),
            OrderStatus::Shipped(tracking) => format!("배송 중 (운송장 {tracking})"),
            OrderStatus::Cancelled { reason, refund: true } => format!("취소·환불: {reason}"),
            OrderStatus::Cancelled { reason, .. } => format!("취소: {reason}"),
        }
    }
}

fn main() {
    let orders = [
        OrderStatus::Pending,
        OrderStatus::Paid { amount: 15_000 },
        OrderStatus::Shipped("CJ-1234".into()),
        OrderStatus::Cancelled { reason: "단순 변심".into(), refund: true },
    ];
    for o in &orders {
        println!("{}", o.describe());
    }
}
```

<aside>  
🔍

`match` 는 **모든 경우를 다뤘는지(exhaustive)** 검사합니다. 나중에 `Refunded` 상태를 추가하면, 처리하지 않은 모든 `match` 에서 컴파일 오류가 나서 빠뜨린 곳을 알려줍니다.

</aside>

## 🧩 문제 2 — 값이 없을 수도 있는데 null이 없다

검색 결과가 없을 수도 있는 함수를 만들어야 한다.

## 💡 해결 2 — `Option<T>`

```rust
// 표준 라이브러리 정의: enum Option<T> { None, Some(T) }

fn find_user(id: u32) -> Option<&'static str> {
    match id {
        1 => Some("하린"),
        2 => Some("페리스"),
        _ => None,
    }
}

fn main() {
    // 1) match
    match find_user(1) {
        Some(name) => println!("찾음: {name}"),
        None => println!("없음"),
    }

    // 2) if let: 한 가지 경우만 관심 있을 때
    if let Some(name) = find_user(2) {
        println!("안녕, {name}");
    }

    // 3) let-else: 없으면 일찍 빠져나가기
    let Some(name) = find_user(1) else {
        println!("사용자 없음");
        return;
    };
    println!("로그인: {name}");

    // 4) 콤비네이터
    let len = find_user(9).map(|n| n.chars().count()).unwrap_or(0);
    let display = find_user(9).unwrap_or("손님");
    println!("{len} {display}");

    // 5) while let: 값이 있는 동안 반복
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        print!("{top} ");
    }
}
```

<aside>  
⚠️

**함정** — `.unwrap()` 은 `None` 이면 panic입니다. 학습·테스트에서만 쓰고, 실제 코드에서는 `match`, `if let`, `unwrap_or`, `?`(9장)를 사용하세요. 불가피하면 `.expect("이유")` 로 의도를 남기세요.

</aside>

## 🔍 원리 — 패턴 문법 총정리

```rust
fn classify(value: (i32, i32)) -> &'static str {
    match value {
        (0, 0) => "원점",                            // 리터럴
        (x, 0) | (0, x) if x > 0 => "양의 축 위",    // OR 패턴 + 매치 가드
        (_, 0) | (0, _) => "음의 축 위",            // 와일드카드
        (1..=9, 1..=9) => "작은 1사분면",           // 범위 패턴
        (x, y) if x == y => "대각선",
        _ => "기타",
    }
}

fn main() {
    // @ 바인딩: 범위를 검사하면서 값도 바인딩
    let age = 17;
    match age {
        n @ 0..=12 => println!("어린이 {n}"),
        n @ 13..=18 => println!("청소년 {n}"),
        n => println!("성인 {n}"),
    }

    // 슬라이스 패턴
    let args = ["run", "--release", "--verbose"];
    match args {
        [first, .., last] => println!("처음 {first}, 마지막 {last}"),
    }
    if let [cmd, rest @ ..] = &args[..] {
        println!("명령 {cmd}, 옵션 {rest:?}");
    }

    // 구조체 분해
    struct P { x: i32, y: i32 }
    let P { x, y: py } = P { x: 1, y: 2 };
    println!("{x} {py} {}", classify((3, 3)));

    // matches! 매크로
    let c = 'k';
    println!("{}", matches!(c, 'a'..='z'));
}
```

    ```rust
    enum Op { Add(f64, f64), Sub(f64, f64), Div(f64, f64) }
    
    fn eval(op: Op) -> Option<f64> {
        match op {
            Op::Add(a, b) => Some(a + b),
            Op::Sub(a, b) => Some(a - b),
            Op::Div(_, b) if b == 0.0 => None,
            Op::Div(a, b) => Some(a / b),
        }
    }
    ```

    fn min_max(values: &[i32]) -> Option<(i32, i32)> {
        let (&first, rest) = values.split_first()?;
