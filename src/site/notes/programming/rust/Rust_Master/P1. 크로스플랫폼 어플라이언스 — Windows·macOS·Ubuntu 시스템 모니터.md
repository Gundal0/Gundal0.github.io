## 🧩 문제 1 — OS마다 시스템 정보를 읽는 방법이 다르다

Windows는 WMI, macOS는 sysctl, Linux는 `/proc` 를 읽어야 합니다.

## 💡 해결 1 — `sysinfo` 로 추상화하고 우리 도메인 타입으로 감싼다

```rust
// src/snapshot.rs
use serde::Serialize;
use sysinfo::{Disks, System};

#[derive(Debug, Serialize)]
pub struct DiskInfo {
    pub mount: String,
    pub used_bytes: u64,
    pub total_bytes: u64,
}

#[derive(Debug, Serialize)]
pub struct Snapshot {
    pub host: String,
    pub os: String,
    pub cpu_cores: usize,
    pub cpu_usage: f32,
    pub mem_used: u64,
    pub mem_total: u64,
    pub uptime_secs: u64,
    pub disks: Vec<DiskInfo>,
}

impl Snapshot {
    pub fn mem_percent(&self) -> f64 {
        if self.mem_total == 0 { 0.0 } else { self.mem_used as f64 / self.mem_total as f64 * 100.0 }
    }
}

pub struct Collector {
    sys: System,
}

impl Collector {
    pub fn new() -> Self {
        let mut sys = System::new_all();
        // CPU 사용률은 두 번 측정한 차이로 계산되므로 최소 간격만큼 기다렸다 다시 갱신
        std::thread::sleep(sysinfo::MINIMUM_CPU_UPDATE_INTERVAL);
        sys.refresh_all();
        Self { sys }
    }

    pub fn collect(&mut self) -> Snapshot {
        self.sys.refresh_all();
        let disks = Disks::new_with_refreshed_list()
            .iter()
            .map(|d| DiskInfo {
                mount: d.mount_point().display().to_string(),
                used_bytes: d.total_space() - d.available_space(),
                total_bytes: d.total_space(),
            })
            .filter(|d| d.total_bytes > 0)
            .collect();

        Snapshot {
            host: System::host_name().unwrap_or_else(|| "unknown".into()),
            os: format!(
                "{} {}",
                System::name().unwrap_or_default(),
                System::os_version().unwrap_or_default()
            ),
            cpu_cores: self.sys.cpus().len(),
            cpu_usage: self.sys.global_cpu_usage(),
            mem_used: self.sys.used_memory(),
            mem_total: self.sys.total_memory(),
            uptime_secs: System::uptime(),
            disks,
        }
    }
}
```

<aside>  
📌

`sysinfo` 는 버전마다 API 이름이 조금씩 바뀝니다(예: 예전의 `global_cpu_info().cpu_usage()` → 현재 `global_cpu_usage()`). 컴파일 오류가 나면 [docs.rs/sysinfo](https://docs.rs/sysinfo)에서 설치된 버전의 문서를 확인하세요.

</aside>

## 🧩 문제 2 — 바이트 숫자는 사람이 읽기 어렵다

## 💡 해결 2 — 출력 모듈 + 단위 테스트

```rust
// src/render.rs
use crate::snapshot::Snapshot;

pub fn gib(bytes: u64) -> f64 { bytes as f64 / 1024f64.powi(3) }

pub fn bar(percent: f64, width: usize) -> String {
    let filled = ((percent / 100.0) * width as f64).round().clamp(0.0, width as f64) as usize;
    format!("{}{}", "█".repeat(filled), "░".repeat(width - filled))
}

pub fn uptime(secs: u64) -> String {
    let (d, h, m) = (secs / 86_400, secs % 86_400 / 3_600, secs % 3_600 / 60);
    format!("{d}d {h}h {m}m")
}

pub fn text(s: &Snapshot) -> String {
    let mut out = format!("🦀 crabmon — {} ({})\n", s.host, s.os);
    out += &format!("├─ CPU    : {} cores, {:.1}% 사용\n", s.cpu_cores, s.cpu_usage);
    out += &format!(
        "├─ Memory : {:.1} / {:.1} GiB ({:.0}%)  {}\n",
        gib(s.mem_used), gib(s.mem_total), s.mem_percent(), bar(s.mem_percent(), 10)
    );
    out += &format!("├─ Uptime : {}\n└─ Disks\n", uptime(s.uptime_secs));
    for d in &s.disks {
        let pct = d.used_bytes as f64 / d.total_bytes as f64 * 100.0;
        out += &format!("   └─ {} : {:.1} / {:.1} GiB ({:.0}%)\n", d.mount, gib(d.used_bytes), gib(d.total_bytes), pct);
    }
    out
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test] fn bar_half() { assert_eq!(bar(50.0, 4), "██░░"); }
    #[test] fn bar_clamps() { assert_eq!(bar(150.0, 3), "███"); }
    #[test] fn uptime_fmt() { assert_eq!(uptime(90_061), "1d 1h 1m"); }
}
```

## 🧩 문제 3 — 옵션 처리를 손으로 파싱하기 싫다

## 💡 해결 3 — `clap` derive + 종료 코드

```rust
// src/main.rs
mod render;
mod snapshot;

use clap::Parser;
use snapshot::Collector;
use std::{process::ExitCode, thread, time::Duration};

/// 가벼운 크로스플랫폼 시스템 모니터
#[derive(Parser, Debug)]
#[command(version, about)]
struct Cli {
    /// JSON으로 출력
    #[arg(long)]
    json: bool,
    /// N초마다 갱신 (Ctrl+C로 종료)
    #[arg(long, value_name = "SECS")]
    watch: Option<u64>,
    /// 메모리 사용률이 이 값(%)을 넘으면 종료 코드 2
    #[arg(long, value_name = "PERCENT", value_parser = clap::value_parser!(u8).range(1..=100))]
    alert_mem: Option<u8>,
}

fn main() -> ExitCode {
    let cli = Cli::parse();
    let mut collector = Collector::new();

    loop {
        let snap = collector.collect();

        if cli.json {
            println!("{}", serde_json::to_string_pretty(&snap).expect("직렬화 실패"));
        } else {
            if cli.watch.is_some() { print!("\x1B[2J\x1B[H"); } // 화면 지우기 (Windows Terminal·macOS·Linux 모두 지원)
            print!("{}", render::text(&snap));
        }

        if let Some(limit) = cli.alert_mem {
            if snap.mem_percent() > limit as f64 {
                eprintln!("⚠️ 메모리 {:.0}% > {limit}%", snap.mem_percent());
                return ExitCode::from(2);
            }
        }

        match cli.watch {
            Some(secs) => thread::sleep(Duration::from_secs(secs.max(1))),
            None => return ExitCode::SUCCESS,
        }
    }
}
```

## 🧩 문제 4 — OS별로 다르게 동작해야 하는 부분이 있다

## 💡 해결 4 — 조건부 컴파일 `#[cfg]`

```rust
/// 로그 파일을 저장할 OS별 권장 위치
pub fn log_dir() -> std::path::PathBuf {
    #[cfg(target_os = "windows")]
    { std::env::var("LOCALAPPDATA").map(Into::into).unwrap_or_else(|_| "C:\\crabmon".into()) }

    #[cfg(target_os = "macos")]
    { std::env::var("HOME").map(|h| format!("{h}/Library/Logs/crabmon").into()).unwrap_or_default() }

    #[cfg(target_os = "linux")]
    { "/var/log/crabmon".into() }
}

fn main_os_hint() {
    if cfg!(windows) { println!("Windows: 작업 스케줄러로 주기 실행을 등록하세요"); }
    else { println!("Unix: cron 또는 systemd timer를 사용하세요"); }
}
```

## 2단계 — 세 OS용 실행 파일 만들기

각 OS에서 직접 빌드

가장 확실한 방법입니다. 각 OS의 Antigravity 터미널에서:

```bash
cargo build --release
# Windows: target\release\crabmon.exe
# macOS / Ubuntu: target/release/crabmon
```

결과물은 **런타임 설치가 필요 없는 단일 실행 파일**입니다. 복사만 하면 됩니다.

크로스 컴파일

```bash
# 대상 플랫폼 추가
rustup target add x86_64-unknown-linux-musl   # 의존성 없는 정적 Linux 바이너리
rustup target add aarch64-apple-darwin        # Apple Silicon (macOS에서)
rustup target add x86_64-pc-windows-gnu

# Linux용 크로스 빌드는 Docker 기반 cross 도구가 편합니다
cargo install cross
cross build --release --target x86_64-unknown-linux-musl
```

macOS 바이너리는 Apple SDK 라이선스 문제로 **macOS에서 빌드**하는 것이 원칙입니다.

GitHub Actions

푸시할 때마다 세 OS에서 자동 빌드·테스트합니다.

```yaml
# .github/workflows/release.yml
name: build
on: [push]
jobs:
  build:
    strategy:
      matrix:
        os: [windows-latest, macos-latest, ubuntu-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test
      - run: cargo build --release
      - uses: actions/upload-artifact@v4
        with:
          name: crabmon-${{ matrix.os }}
          path: |
            target/release/crabmon
            target/release/crabmon.exe
```
