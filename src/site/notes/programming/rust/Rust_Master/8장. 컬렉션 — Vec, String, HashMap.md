> 📖 **스토리** — 마케팅팀이 고객 리뷰 텍스트를 주며 "가장 많이 나온 단어 TOP 5"를 물었다. 개수를 모르는 데이터를 담을 그릇이 필요하다.

## 🧩 문제 1 — 배열은 크기가 고정되어 있다

## 💡 해결 1 — `Vec<T>`: 늘어나는 배열

```rust
fn main() {
    let mut scores: Vec<u32> = Vec::new();
    scores.push(90);
    scores.extend([75, 88, 62]);
    let mut more = vec![100, 55];          // vec! 매크로
    scores.append(&mut more);

    println!("{:?}", scores.get(10));      // None — 안전한 접근
    println!("{}", scores[0]);             // 90 — 범위 밖이면 panic

    scores.sort_unstable_by(|a, b| b.cmp(a)); // 내림차순
    scores.retain(|&s| s >= 60);           // 조건에 맞는 것만 남기기
    scores.dedup();                        // 연속 중복 제거
    let top3: Vec<u32> = scores.iter().take(3).copied().collect();
    println!("{scores:?} → TOP3 {top3:?}");

    if let Some(last) = scores.last_mut() { *last += 1; }
    println!("포함? {}", scores.contains(&100));
}
```

## 🧩 문제 2 — `String` 과 `&str` 이 헷갈린다

## 💡 해결 2 — 소유하는 문자열 vs 빌린 문자열

<aside>  
📦

**`String`**

힙에 있는 소유 문자열. 크기 변경·수정 가능. 구조체 필드나 반환값에 주로 사용.

</aside>

<aside>  
🔍

**`&str`**

문자열의 일부를 가리키는 빌린 참조(슬라이스). 읽기 전용. 함수 매개변수에 주로 사용.

</aside>

```rust
fn main() {
    let mut s = String::from("Hello");
    s.push(',');
    s.push_str(" 러스트");
    let greeting = s.clone() + "!";        // + 는 왼쪽 String의 소유권을 가져감
    let joined = format!("{s} / {greeting}"); // 소유권을 가져가지 않아 편리

    println!("바이트 {} / 글자 {}", s.len(), s.chars().count()); // 한글은 다름!
    for word in s.split(' ') { println!("[{word}]"); }
    println!("{}", s.to_uppercase());
    println!("{}", s.replace("러스트", "Rust"));
    println!("{}", "  trim me  ".trim());
    println!("{}", s.starts_with("Hell"));
    println!("{joined}");

    let owned: String = "리터럴".to_string();  // &str → String
    let borrowed: &str = &owned;               // String → &str
    println!("{borrowed}");
}
```

## 🧩 문제 3 — 단어별 등장 횟수를 세고 싶다

## 💡 해결 3 — `HashMap` + Entry API

```rust
use std::collections::HashMap;

fn top_words(text: &str, n: usize) -> Vec<(String, usize)> {
    let mut counts: HashMap<String, usize> = HashMap::new();

    for word in text.split_whitespace() {
        let word = word
            .trim_matches(|c: char| !c.is_alphanumeric())
            .to_lowercase();
        if word.is_empty() { continue; }
        *counts.entry(word).or_insert(0) += 1;   // 없으면 0으로 넣고 +1
    }

    let mut pairs: Vec<(String, usize)> = counts.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1).then_with(|| a.0.cmp(&b.0)));
    pairs.truncate(n);
    pairs
}

fn main() {
    let reviews = "배송 빠름! 품질 좋음. 배송 최고, 품질도 좋음 배송";
    for (word, count) in top_words(reviews, 3) {
        println!("{word:<6} {count}");
    }

    // 기타 연산
    let mut stock = HashMap::from([("사과", 3), ("배", 0)]);
    stock.insert("포도", 7);
    if let Some(q) = stock.get_mut("사과") { *q -= 1; }
    stock.remove("배");
    println!("{:?} {}", stock.get("포도"), stock.contains_key("배"));
}
```

## 🔍 원리 — 컬렉션 고르기

|타입|용도|
|---|---|
|`Vec<T>`|기본 선택. 순서 있는 목록|
|`VecDeque<T>`|양쪽 끝에서 넣고 빼기 (큐)|
|`HashMap<K, V>`|키→값 조회, 순서 없음|
|`BTreeMap<K, V>`|키 순서대로 정렬된 맵, 범위 검색|
|`HashSet<T>` / `BTreeSet<T>`|중복 없는 집합, 교집합·합집합|
|`BinaryHeap<T>`|우선순위 큐 (최대값 먼저)|

## 🏋️ 연습 문제

- Q1. 학생 이름과 점수 목록 `Vec<(&str, u32)>` 을 받아, 학생별 평균을 `BTreeMap<&str, f64>` 로 반환하세요.
    
    ```rust
    use std::collections::BTreeMap;
    
    fn averages<'a>(rows: &[(&'a str, u32)]) -> BTreeMap<&'a str, f64> {
        let mut acc: BTreeMap<&str, (u32, u32)> = BTreeMap::new();
        for &(name, score) in rows {
            let e = acc.entry(name).or_insert((0, 0));
            e.0 += score;
            e.1 += 1;
        }
        acc.into_iter().map(|(k, (sum, n))| (k, sum as f64 / n as f64)).collect()
    }
    ```
    
    `<'a>` 는 13장에서 배울 라이프타임입니다.
