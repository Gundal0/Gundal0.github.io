## 🧩 문제 1 — 정렬 기준을 함수 안에서 정하고 싶다

## 💡 해결 1 — 클로저: 환경을 캡처하는 익명 함수

```rust
fn main() {
    let threshold = 10_000;                       // 환경 변수
    let is_big = |amount: u32| amount >= threshold; // threshold를 빌려서 캡처
    println!("{}", is_big(15_000));

    let mut log = Vec::new();
    let mut record = |msg: &str| log.push(msg.to_string()); // 가변 캡처 → FnMut
    record("시작");
    record("끝");
    println!("{log:?}");

    let name = String::from("하린");
    let consume = move || name;                    // 소유권을 가져감 → FnOnce
    let taken = consume();
    println!("{taken}");
}
```

|트레이트|캡처 방식|호출 횟수|
|---|---|---|
|`Fn`|불변 빌림 `&T`|여러 번, 동시에도|
|`FnMut`|가변 빌림 `&mut T`|여러 번|
|`FnOnce`|소유권 이동|한 번|

<aside>  
💡

`move` 키워드는 캡처한 변수의 **소유권을 클로저 안으로 옮깁니다.** 클로저가 다른 스레드로 가거나 함수 밖으로 반환될 때 필수입니다.

</aside>

### 클로저를 인자로 받고, 반환하기

```rust
fn apply_twice<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 { f(f(x)) }

fn make_adder(n: i32) -> impl Fn(i32) -> i32 { move |x| x + n }

fn make_op(kind: &str) -> Box<dyn Fn(i32, i32) -> i32> {
    match kind {
        "add" => Box::new(|a, b| a + b),
        _ => Box::new(|a, b| a * b),
    }
}

fn main() {
    println!("{}", apply_twice(|x| x * 3, 2));   // 18
    let add5 = make_adder(5);
    println!("{} {}", add5(1), make_op("mul")(3, 4)); // 6 12
    let f: fn(i32) -> i32 = add5_fn;               // 일반 함수 포인터도 가능
    println!("{}", apply_twice(f, 0));             // 10
}
fn add5_fn(x: i32) -> i32 { x + 5 }
```

## 🧩 문제 2 — 중첩 for문을 없애고 싶다

## 💡 해결 2 — 이터레이터 도구상자

```rust
#[derive(Debug)]
struct Order { city: &'static str, amount: u32, paid: bool }

fn main() {
    let orders = vec![
        Order { city: "서울", amount: 32_000, paid: true },
        Order { city: "부산", amount: 50_000, paid: true },
        Order { city: "서울", amount: 12_000, paid: false },
        Order { city: "서울", amount: 87_000, paid: true },
        Order { city: "서울", amount: 45_000, paid: true },
    ];

    let mut top: Vec<&Order> = orders
        .iter()
        .filter(|o| o.city == "서울" && o.paid)
        .collect();
    top.sort_by_key(|o| std::cmp::Reverse(o.amount));
    let top3: Vec<u32> = top.iter().take(3).map(|o| o.amount).collect();
    println!("{top3:?}"); // [87000, 45000, 32000]

    let total: u32 = orders.iter().filter(|o| o.paid).map(|o| o.amount).sum();
    let any_unpaid = orders.iter().any(|o| !o.paid);
    let first_busan = orders.iter().position(|o| o.city == "부산");
    let (paid, unpaid): (Vec<&Order>, Vec<&Order>) = orders.iter().partition(|o| o.paid);
    println!("{total} {any_unpaid} {first_busan:?} {}/{}", paid.len(), unpaid.len());

    // zip, enumerate, chain, flat_map, windows, rev
    let names = ["a", "b", "c"];
    for (i, (n, o)) in names.iter().zip(orders.iter()).enumerate() {
        println!("{i}: {n} → {}", o.amount);
    }
    let words: Vec<&str> = ["hello world", "rust lang"].iter().flat_map(|s| s.split(' ')).collect();
    let diffs: Vec<i32> = [1, 4, 9, 16].windows(2).map(|w| w[1] - w[0]).collect();
    println!("{words:?} {diffs:?}");
}
```

<aside>  
🔍

**지연 평가(lazy)** — `map`, `filter` 같은 어댑터는 `collect`, `sum`, `for` 처럼 **소비자**가 호출될 때까지 아무 일도 하지 않습니다. 컴파일러가 체인 전체를 하나의 루프로 최적화하므로 손으로 쓴 for문만큼 빠릅니다(_zero-cost abstraction_).

</aside>

### `iter()` vs `iter_mut()` vs `into_iter()`

|메서드|항목 타입|원본|
|---|---|---|
|`iter()`|`&T`|유지|
|`iter_mut()`|`&mut T`|수정 가능|
|`into_iter()`|`T`|소비됨(move)|

## 🧩 문제 3 — 나만의 수열을 for문에서 쓰고 싶다

## 💡 해결 3 — `Iterator` 트레이트 구현

```rust
struct Fibonacci { a: u64, b: u64 }

impl Iterator for Fibonacci {
    type Item = u64;
    fn next(&mut self) -> Option<u64> {
        let next = self.a.checked_add(self.b)?; // 오버플로 나면 끝
        let current = self.a;
        self.a = self.b;
        self.b = next;
        Some(current)
    }
}

fn fib() -> Fibonacci { Fibonacci { a: 0, b: 1 } }

fn main() {
    let evens: Vec<u64> = fib().filter(|n| n % 2 == 0).take_while(|&n| n < 1000).collect();
    println!("{evens:?}");                // [0, 2, 8, 34, 144, 610]
    println!("{}", fib().count());       // u64 범위 안의 피보나치 개수

    // 간단한 경우는 std::iter 도우미로
    let squares = std::iter::successors(Some(1u32), |&x| x.checked_mul(2));
    println!("{:?}", squares.take(5).collect::<Vec<_>>()); // [1, 2, 4, 8, 16]
}
```
