> 📖 **스토리** — 알림 시스템을 만들어야 한다. 이메일, 슬랙, SMS는 보내는 방법이 모두 다르지만, 호출하는 쪽에서는 그냥 `send()` 만 부르고 싶다.

## 🧩 문제 1 — 공통 동작을 어떻게 정의하지?

## 💡 해결 1 — 트레이트 정의와 구현

```rust
trait Notifier {
    fn channel(&self) -> &str;                   // 필수 메서드
    fn send(&self, msg: &str) -> Result<(), String>;

    fn send_urgent(&self, msg: &str) -> Result<(), String> {  // 기본 구현
        self.send(&format!("🚨 [긴급] {msg}"))
    }
}

struct Email { to: String }
struct Slack { webhook: String }

impl Notifier for Email {
    fn channel(&self) -> &str { "email" }
    fn send(&self, msg: &str) -> Result<(), String> {
        println!("📧 {} 에게: {msg}", self.to);
        Ok(())
    }
}

impl Notifier for Slack {
    fn channel(&self) -> &str { "slack" }
    fn send(&self, msg: &str) -> Result<(), String> {
        println!("💬 {} 로: {msg}", self.webhook);
        Ok(())
    }
    fn send_urgent(&self, msg: &str) -> Result<(), String> { // 기본 구현 재정의
        self.send(&format!("<!channel> {msg}"))
    }
}
```

## 🧩 문제 2 — 모든 채널에 한 번에 보내고 싶다

## 💡 해결 2 — 정적 디스패치 vs 동적 디스패치

```rust
// 정적 디스패치: 컴파일 시 타입 결정, 가장 빠름
fn notify_one(n: &impl Notifier, msg: &str) {
    let _ = n.send(msg);
}

// 동적 디스패치: 서로 다른 타입을 한 컨테이너에 (vtable 경유)
fn broadcast(targets: &[Box<dyn Notifier>], msg: &str) {
    for t in targets {
        if let Err(e) = t.send(msg) {
            eprintln!("{} 실패: {e}", t.channel());
        }
    }
}

fn main() {
    let targets: Vec<Box<dyn Notifier>> = vec![
        Box::new(Email { to: "harin@crab.dev".into() }),
        Box::new(Slack { webhook: "#ops".into() }),
    ];
    broadcast(&targets, "배포 완료");
    notify_one(&Email { to: "ferris@crab.dev".into() }, "리뷰 요청");
    let _ = targets[1].send_urgent("서버 다운");
}
```

|구분|`impl Trait` / `<T: Trait>`|`dyn Trait`|
|---|---|---|
|결정 시점|컴파일 타임|런타임 (vtable)|
|성능|인라인 가능, 최고|간접 호출 비용 약간|
|서로 다른 타입 혼합|불가|가능 (`Vec<Box<dyn T>>`)|
|제약|-|dyn 호환(object safe) 트레이트만: 제네릭 메서드·`Self` 반환 불가|

## 🧩 문제 3 — 내 타입에 `+` 와 `{}` 를 쓰고 싶다

## 💡 해결 3 — 표준 트레이트 구현

```rust
use std::fmt;
use std::ops::{Add, Mul};

#[derive(Debug, Clone, Copy, PartialEq, Default)]
struct Money { won: i64 }

impl Add for Money {                         // a + b
    type Output = Money;
    fn add(self, rhs: Money) -> Money { Money { won: self.won + rhs.won } }
}

impl Mul<i64> for Money {                    // a * 3
    type Output = Money;
    fn mul(self, k: i64) -> Money { Money { won: self.won * k } }
}

impl fmt::Display for Money {                // println!("{}")
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(f, "₩{}", self.won)
    }
}

impl From<i64> for Money {                   // Money::from(1000), 1000.into()
    fn from(won: i64) -> Self { Money { won } }
}

impl std::iter::Sum for Money {              // iter().sum()
    fn sum<I: Iterator<Item = Money>>(iter: I) -> Self {
        iter.fold(Money::default(), |a, b| a + b)
    }
}

fn main() {
    let price: Money = 12_000.into();
    let total = price * 2 + Money::from(3_000);
    let cart_sum: Money = vec![price, total].into_iter().sum();
    println!("{total} / {cart_sum}"); // ₩27000 / ₩39000
}
```

### 📋 꼭 알아야 할 표준 트레이트

|트레이트|역할|derive|
|---|---|---|
|`Debug` / `Display`|`{:?}` / `{}` 출력|Debug만 가능|
|`Clone` / `Copy`|명시적 복제 / 암묵적 복사|✅|
|`PartialEq` / `Eq`|`==` 비교|✅|
|`PartialOrd` / `Ord`|`<` 비교, 정렬|✅|
|`Hash`|HashMap 키|✅|
|`Default`|기본값|✅|
|`From` / `Into` / `TryFrom`|타입 변환|-|
|`AsRef` / `Borrow`|저렴한 참조 변환|-|
|`Iterator` / `IntoIterator`|`for` 루프|-|
|`Drop` / `Deref`|해제 시 동작 / `*` 연산|-|
|`Send` / `Sync`|스레드 간 전달·공유|자동|

## 🔍 원리 — 고아 규칙과 블랭킷 구현

<aside>  
📜

**고아 규칙(orphan rule)**: 트레이트와 타입 중 **하나는 내 크레이트**에 있어야 구현할 수 있다. `impl Display for Vec<i32>` 는 둘 다 표준 라이브러리 것이라 불가 → newtype(`struct MyVec(Vec<i32>)`)으로 감싸세요.

</aside>

```rust
trait Describe { fn describe(&self) -> String; }

// 블랭킷 구현: Debug를 구현한 모든 타입에 Describe를 자동 제공
impl<T: std::fmt::Debug> Describe for T {
    fn describe(&self) -> String { format!("값: {self:?}") }
}

fn main() {
    println!("{}", 42.describe());
    println!("{}", vec![1, 2].describe());
}
```
