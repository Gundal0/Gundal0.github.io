> 📖 **스토리** — 설정 구조체 20개마다 똑같은 `describe()` 구현을 복사하고 있었다. 페리스: "`println!` 과 `vec!` 뒤에서 무슨 일이 일어나는지 볼 때가 됐군."

## 🔍 원리 — 매크로의 종류

|종류|모양|예|
|---|---|---|
|**선언적 매크로** `macro_rules!`|`name!(...)`|`vec!`, `println!`, `assert_eq!`|
|**derive 매크로** (절차적)|`#[derive(Name)]`|`Serialize`, `Parser`|
|**속성 매크로** (절차적)|`#[name]`|`#[tokio::main]`, `#[test]`|
|**함수형 매크로** (절차적)|`name!(...)`|`sqlx::query!`, `html!`|

함수와 달리 매크로는 가변 개수의 인자를 받고, 컴파일 전에 **코드로 펼쳐집니다(expand)**.

## 🧩 문제 1 — HashMap을 리터럴처럼 만들고 싶다

## 💡 해결 1 — `macro_rules!` 와 반복 패턴

```rust
macro_rules! hashmap {
    // $( ... ),*  : 쉼표로 구분된 0회 이상 반복,  $(,)? : 끝의 쉼표 허용
    ( $( $key:expr => $value:expr ),* $(,)? ) => {{
        let mut map = ::std::collections::HashMap::new();
        $( map.insert($key, $value); )*
        map
    }};
}

macro_rules! square {
    ($x:expr) => { $x * $x };
}

macro_rules! make_getter {
    // ident로 이름을, ty로 타입을 받아 함수 생성
    ($name:ident, $t:ty, $v:expr) => {
        fn $name() -> $t { $v }
    };
}
make_getter!(default_port, u16, 8080);

fn main() {
    let scores = hashmap! { "하린" => 90, "페리스" => 100, };
    println!("{scores:?} {} {}", square!(2 + 3), default_port()); // square!(2+3)=25 (식 단위로 치환)
}
```

|조각 지정자|매칭 대상|
|---|---|
|`expr` / `ty` / `ident`|식 / 타입 / 식별자|
|`pat` / `stmt` / `block`|패턴 / 문 / 블록|
|`literal` / `lifetime` / `path`|리터럴 / 라이프타임 / 경로|
|`tt`|아무 토큰 트리 하나 (가장 유연)|

반복: `$(...)*`(0회 이상), `$(...)+`(1회 이상), `$(...)?`(0~1회). 다른 크레이트에 공개하려면 `#[macro_export]` 를 붙입니다.

<aside>  
🔍

**위생성(hygiene)** — 매크로 안에서 만든 `map` 변수는 호출하는 쪽의 `map` 과 충돌하지 않습니다. 또 경로는 `::std::...` 처럼 절대 경로로 쓰는 것이 안전합니다.

</aside>

## 🧩 문제 2 — 구조체의 필드 목록을 읽어 코드를 생성하고 싶다

## 💡 해결 2 — 절차적 derive 매크로

절차적 매크로는 **별도 크레이트**(`proc-macro = true`)에 두고, 토큰 스트림을 받아 토큰 스트림을 돌려줍니다. `syn` 으로 파싱하고 `quote` 로 코드를 만듭니다.

```
describe_workspace/
├── Cargo.toml          # [workspace] members = ["describe_derive", "app"]
├── describe_derive/    # 매크로 크레이트
└── app/                # 사용처
```

```toml
# describe_derive/Cargo.toml
[lib]
proc-macro = true

[dependencies]
syn = { version = "2", features = ["full"] }
quote = "1"
proc-macro2 = "1"
```

```rust
// describe_derive/src/lib.rs
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, Data, DeriveInput, Fields};

#[proc_macro_derive(Describe)]
pub fn derive_describe(input: TokenStream) -> TokenStream {
    let ast = parse_macro_input!(input as DeriveInput);
    let name = &ast.ident;

    let field_names: Vec<String> = match &ast.data {
        Data::Struct(s) => match &s.fields {
            Fields::Named(named) => named
                .named
                .iter()
                .map(|f| f.ident.as_ref().unwrap().to_string())
                .collect(),
            _ => vec![],
        },
        _ => vec![],
    };

    let expanded = quote! {
        impl #name {
            pub fn describe() -> String {
                format!("{} {{ {} }}", stringify!(#name), [#(#field_names),*].join(", "))
            }
        }
    };
    expanded.into()
}
```

```rust
// app/src/main.rs   (app/Cargo.toml: describe_derive = { path = "../describe_derive" })
use describe_derive::Describe;

#[derive(Describe)]
struct ServerConfig { host: String, port: u16, workers: usize }

fn main() {
    println!("{}", ServerConfig::describe()); // ServerConfig { host, port, workers }
}
```

<aside>  
🤖

**Antigravity 팁** — rust-analyzer의 명령 팔레트에서 _rust-analyzer: Expand macro recursively at caret_ 을 실행하면 매크로가 펼쳐진 결과를 바로 볼 수 있습니다. 터미널에서는 `cargo install cargo-expand` 후 `cargo expand` 로 확인합니다.

</aside>

<aside>  
⚠️

**함정** — 매크로는 강력하지만 디버깅이 어렵고 컴파일 시간을 늘립니다. **함수나 제네릭, 트레이트로 해결할 수 없을 때만** 매크로를 쓰세요.

</aside>
