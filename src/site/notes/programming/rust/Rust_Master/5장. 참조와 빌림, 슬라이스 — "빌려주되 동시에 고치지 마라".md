> 📖 **스토리** — 장바구니 목록을 여러 함수가 읽고 고쳐야 한다. 소유권을 주고받다 보니 코드가 엉망이 됐다. 페리스가 화이트보드에 두 줄을 썼다. "읽는 사람은 여럿, 고치는 사람은 한 명."

## 🧩 문제 1 — 함수가 목록을 고치게 하고 싶다

## 💡 해결 1 — 불변 참조 `&T` 와 가변 참조 `&mut T`

```rust
fn total_items(cart: &Vec<String>) -> usize {   // 읽기만
    cart.len()
}

fn add_item(cart: &mut Vec<String>, item: &str) { // 수정
    cart.push(item.to_string());
}

fn main() {
    let mut cart = vec!["사과".to_string()];
    add_item(&mut cart, "바나나");
    println!("{}개: {:?}", total_items(&cart), cart); // 2개: ["사과", "바나나"]
}
```

## 🧩 문제 2 — E0502: cannot borrow as mutable because it is also borrowed as immutable

```rust
fn main() {
    let mut cart = vec!["사과".to_string()];
    let first = &cart[0];          // 불변 빌림 시작
    cart.push("포도".to_string()); // ❌ 가변 빌림 시도
    println!("{first}");           // 불변 빌림이 여기까지 살아 있음
}
```

## 🔍 원리 — 빌림 규칙

<aside>  
📜

어느 시점에든 다음 중 **하나만** 가능하다.

- 불변 참조 `&T` 를 **여러 개**
- 가변 참조 `&mut T` 를 **딱 하나**

그리고 참조는 항상 **유효한 값**을 가리켜야 한다.

</aside>

왜 위 코드가 위험할까요? `Vec` 는 `push` 할 때 용량이 부족하면 **더 큰 메모리로 이사**합니다. 그러면 `first` 는 이미 해제된 옛 주소를 가리키게 됩니다(dangling). Rust는 이를 컴파일 단계에서 막습니다.

## 💡 해결 2 — 빌림의 범위를 줄이거나 값을 복사한다

```rust
fn main() {
    let mut cart = vec!["사과".to_string()];

    // 방법 A: 불변 참조를 다 쓴 뒤에 수정 (NLL: 마지막 사용 시점에 빌림 종료)
    let first = &cart[0];
    println!("{first}");
    cart.push("포도".to_string()); // ✅

    // 방법 B: 필요한 값을 복제해 두기
    let first = cart[0].clone();
    cart.push("배".to_string());
    println!("{first}");             // ✅
}
```

## 🧩 문제 3 — 문자열의 첫 단어만 돌려주고 싶다

인덱스를 반환하면 원본 문자열이 바뀐 뒤에도 그 숫자가 남아 버그가 됩니다.

## 💡 해결 3 — 슬라이스 `&str`, `&[T]`

슬라이스는 컬렉션의 **일부분을 가리키는 참조**(포인터 + 길이)입니다. 원본이 살아 있는 동안만 유효하므로 안전합니다.

```rust
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

fn sum(values: &[i32]) -> i32 {
    values.iter().sum()
}

fn main() {
    let title = String::from("Rust 마스터 클래스");
    let word = first_word(&title);    // &String → &str 자동 변환(Deref)
    println!("{word}");                // Rust
    println!("{}", first_word("리터럴도 됩니다")); // 문자열 리터럴은 &'static str

    let nums = [1, 2, 3, 4, 5];
    println!("{}", sum(&nums[1..4])); // 2+3+4 = 9
    println!("{}", sum(&nums[..2]));  // 1+2 = 3
}
```

<aside>  
⚠️

**함정 — 한글 문자열 슬라이싱**

`&str` 의 인덱스는 **바이트** 단위입니다. 한글은 UTF-8에서 글자당 3바이트이므로 `&"하린"[0..1]` 은 글자 경계가 아니어서 panic이 납니다. 글자 단위는 `s.chars()`, 안전한 슬라이스는 `s.get(0..3)` 을 쓰세요.

</aside>

<aside>  
💡

**함수 매개변수 관용구**: `&String` 대신 `&str`, `&Vec<T>` 대신 `&[T]` 를 받으세요. 더 많은 종류의 입력(리터럴, 배열, 일부분)을 받을 수 있습니다.

</aside>

## 🔍 참고 — 역참조와 자동 참조

```rust
let mut n = 10;
let r = &mut n;
*r += 1;                // * 로 참조가 가리키는 값에 접근
println!("{n}");        // 11

let s = String::from("hi");
let rs = &s;
println!("{}", rs.len()); // 메서드 호출 시에는 자동으로 역참조됨
```
