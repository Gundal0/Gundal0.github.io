> 📖 **스토리** — 금요일에 할인 로직을 고쳤는데 월요일에 배송비 계산이 깨져 있었다. 페리스: "테스트는 미래의 나에게 보내는 안전망이야. 그리고 Rust는 그걸 언어에 내장해 뒀지."

## 🧩 문제 1 — 함수가 올바른지 자동으로 확인하고 싶다

## 💡 해결 1 — 단위 테스트

```rust
// src/lib.rs
pub fn shipping_fee(total: u32) -> u32 {
    if total >= 50_000 { 0 } else { 3_000 }
}

pub fn apply_discount(price: u32, percent: u8) -> u32 {
    assert!(percent <= 100, "할인율은 100을 넘을 수 없습니다");
    price - price * percent as u32 / 100
}

#[cfg(test)]                 // cargo test 때만 컴파일
mod tests {
    use super::*;

    #[test]
    fn free_shipping_over_50k() {
        assert_eq!(shipping_fee(50_000), 0);
        assert_eq!(shipping_fee(49_999), 3_000, "5만원 미만은 유료");
    }

    #[test]
    fn discount_works() {
        assert_eq!(apply_discount(10_000, 10), 9_000);
        assert_ne!(apply_discount(10_000, 0), 0);
    }

    #[test]
    #[should_panic(expected = "100을 넘을 수 없습니다")]
    fn discount_over_100_panics() {
        apply_discount(1_000, 150);
    }

    #[test]
    fn parse_returns_result() -> Result<(), std::num::ParseIntError> {
        let n: u32 = "42".parse()?;   // 테스트에서도 ? 사용 가능
        assert!(n > 0);
        Ok(())
    }

    #[test]
    #[ignore = "느린 테스트"]   // cargo test -- --ignored 로 따로 실행
    fn slow_test() {}
}
```

```bash
cargo test                      # 전체
cargo test discount             # 이름에 discount가 들어간 테스트만
cargo test -- --nocapture       # println! 출력 보기
cargo test -- --test-threads=1  # 순차 실행
```

## 🧩 문제 2 — 외부 사용자 관점에서도 테스트하고 싶다

## 💡 해결 2 — 통합 테스트 (`tests/` 디렉터리)

```rust
// tests/checkout.rs  — 각 파일이 별도 크레이트로 컴파일됨 (pub API만 접근 가능)
use shop::{apply_discount, shipping_fee};

#[test]
fn full_checkout() {
    let price = apply_discount(60_000, 20);   // 48,000
    assert_eq!(price + shipping_fee(price), 51_000);
}
```

## 🧩 문제 3 — 문서의 예제 코드가 실제 코드와 다르다

## 💡 해결 3 — 문서 주석 + 문서 테스트

```rust
//! # shop
//! Crab Labs 쇼핑몰 도메인 라이브러리.  (크레이트/모듈 전체 설명은 //!)

/// 주문 금액에 따른 배송비를 계산합니다.  (항목 설명은 ///)
///
/// # Examples
///
/// ```
/// assert_eq!(shop::shipping_fee(70_000), 0);
/// assert_eq!(shop::shipping_fee(1_000), 3_000);
/// ```
///
/// # Panics
/// 이 함수는 panic하지 않습니다.
pub fn shipping_fee(total: u32) -> u32 {
    if total >= 50_000 { 0 } else { 3_000 }
}
```

`cargo test` 는 문서 안의 ````` 코드 블록도 실행합니다. 문서가 낡으면 테스트가 실패하므로 문서와 코드가 항상 일치합니다. `cargo doc --open` 으로 HTML 문서를 볼 수 있습니다.

<aside>  
🤖

**Antigravity 팁** — `#[test]` 위의 **▶ Run Test** 코드 렌즈로 테스트 하나만 실행할 수 있습니다. 에이전트에게 "이 함수의 경계값 테스트를 추가하고 cargo test로 통과를 확인해줘"라고 맡길 때는, 추가된 테스트가 **의미 있는 것을 검사하는지** 반드시 읽어보세요.

</aside>
