> 📖 출시 후 첫 주, 커뮤니티 게시판에 질문이 올라왔다. "플러그인을 만들고 싶은데 어디서부터 시작하나요?" 민준은 이 문서를 써서 답했다. **이 장은 외부 플러그인 개발자에게 그대로 공개하는 문서**입니다.

## 1. 플러그인 구조

```
my-plugin.zip
├── manifest.json      # 필수: id, name, version, permissions ...
└── main.js            # 필수: 번들링된 단일 스크립트 (ES2020, import/export 없음)
```

```json
{
  "id": "word-count",
  "name": "단어 수 세기",
  "version": "1.0.0",
  "author": "홍길동",
  "description": "저장할 때마다 단어 수를 상태 표시줄에 보여줍니다",
  "min_app_version": "1.0.0",
  "permissions": ["ui:status"],
  "main": "main.js"
}
```

|권한|여는 API|
|---|---|
|`editor:read`|`api.editor.getText()`, `api.editor.getSelection()`|
|`editor:write`|`api.editor.replaceSelection(t)`, `api.editor.setText(t)`, onSave에서 문자열 반환으로 변환|
|`vault:read`|`api.vault.list()`, `api.vault.read(path)`|
|`ui:status`|`api.ui.setStatus(text)`|
|(항상 허용)|`api.registerCommand`, `api.onSave`, `api.ui.notice`, `api.storage.get/set`|

<aside>  
💡

**최소 권한 원칙** — 필요한 권한만 요청하세요. 사용자는 설치 시 권한 목록을 보고 동의합니다. `vault:read` 처럼 넓은 권한은 설치율을 떨어뜨립니다.

</aside>

## 2. SDK 타입 정의

```tsx
// crabnote.d.ts — 플러그인 템플릿에 포함
declare namespace CrabNote {
  interface NoteRef { path: string; title: string }
  interface SaveContext { path: string; title: string; text: string }
  interface Api {
    registerCommand(cmd: { id: string; name: string }, handler: () => void | Promise<void>): void;
    /** 문자열을 반환하면 저장될 내용을 바꿉니다(editor:write 필요). undefined면 그대로 */
    onSave(handler: (ctx: SaveContext) => string | void | Promise<string | void>): void;
    editor: {
      getText(): Promise<string>;
      getSelection(): Promise<string>;
      replaceSelection(text: string): Promise<void>;
      setText(text: string): Promise<void>;
    };
    vault: { list(): Promise<NoteRef[]>; read(path: string): Promise<string> };
    ui: { notice(message: string): Promise<void>; setStatus(text: string): Promise<void> };
    storage: { get<T = unknown>(): Promise<T | null>; set(value: unknown): Promise<void> };
  }
}

declare const crabnote: {
  readonly apiVersion: 1;
  onload(fn: (api: CrabNote.Api) => void | Promise<void>): void;
};
```

## 3. 템플릿 프로젝트

```
plugin-template/
├── package.json
├── tsconfig.json
├── crabnote.d.ts
├── manifest.json
└── src/main.ts
```

```json
// plugin-template/package.json
{
  "name": "crabnote-plugin-word-count",
  "private": true,
  "scripts": {
    "build": "esbuild src/main.ts --bundle --format=iife --target=es2020 --outfile=dist/main.js",
    "dev": "esbuild src/main.ts --bundle --format=iife --target=es2020 --watch --outfile=$CRABNOTE_PLUGINS/word-count/main.js",
    "package": "npm run build && cp manifest.json dist/ && cd dist && zip -r ../word-count.zip . && cd .. && shasum -a 256 word-count.zip"
  },
  "devDependencies": { "esbuild": "^0.24.0", "typescript": "^5.6.0" }
}
```

<aside>  
⚠️

**단일 파일 IIFE로 번들**하세요. 플러그인은 클래식 워커에서 실행되므로 `import`/`export` 문을 쓸 수 없고, CSP 때문에 CDN에서 라이브러리를 불러올 수도 없습니다. npm 라이브러리는 esbuild가 main.js 안에 포함시켜 줍니다. Windows PowerShell에서는 `zip`/`shasum` 대신 `Compress-Archive`/`Get-FileHash` 를 쓰세요.

</aside>

## 4. 샘플 플러그인 4종

① word-count (ui:status)

```tsx
// 단어 수를 저장할 때마다 상태 표시줄에 표시. 본문은 바꾸지 않음(undefined 반환)
crabnote.onload((api) => {
  api.onSave(async ({ text }) => {
    const words = text.split(/\s+/).filter(Boolean).length;
    const hangul = (text.match(/[가-힣]/g) ?? []).length;
    await api.ui.setStatus(`🔢 ${words}단어 · 한글 ${hangul}자`);
  });
});
```

```json
{ "id": "word-count", "name": "단어 수 세기", "version": "1.0.0", "author": "Crab Labs",
  "description": "저장 시 단어 수 표시", "permissions": ["ui:status"] }
```

② daily-template (editor:write)

```tsx
// 명령 팔레트에 "회의록 템플릿 삽입" 추가. 마지막 사용 횟수를 storage에 기록
crabnote.onload((api) => {
  api.registerCommand({ id: "meeting", name: "회의록 템플릿 삽입" }, async () => {
    const d = new Date();
    const pad = (n: number) => String(n).padStart(2, "0");
    const today = `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
    await api.editor.replaceSelection(
      `## 📝 ${today} 회의록\n\n- 참석자:\n- 안건:\n\n### 결정 사항\n- \n\n### 액션 아이템\n- [ ] \n`,
    );
    const stats = (await api.storage.get<{ used: number }>()) ?? { used: 0 };
    await api.storage.set({ used: stats.used + 1 });
    await api.ui.notice(`템플릿을 ${stats.used + 1}번 사용했습니다`);
  });
});
```

```json
{ "id": "daily-template", "name": "회의록 템플릿", "version": "1.0.0", "author": "Crab Labs",
  "description": "커서 위치에 회의록 양식 삽입", "permissions": ["editor:write"] }
```

③ tidy-on-save (editor:write)

```tsx
// 저장 시 줄 끝 공백 제거, 연속 빈 줄 2개로 제한, 파일 끝 개행 보장
crabnote.onload((api) => {
  api.onSave(({ text }) =>
    text
      .replace(/[ \t]+$/gm, "")
      .replace(/\n{3,}/g, "\n\n")
      .replace(/\s*$/, "\n"),
  );
});
```

```json
{ "id": "tidy-on-save", "name": "저장 시 정리", "version": "1.0.0", "author": "Crab Labs",
  "description": "공백·빈 줄 정리", "permissions": ["editor:write"] }
```

④ link-stats (vault:read)

```tsx
// Vault 전체를 읽어 가장 많이 링크된 노트 TOP 5를 알림으로
crabnote.onload((api) => {
  api.registerCommand({ id: "top-linked", name: "가장 많이 링크된 노트 TOP 5" }, async () => {
    const notes = await api.vault.list();
    const counts = new Map<string, number>();
    for (const n of notes) {
      const body = await api.vault.read(n.path);
      for (const m of body.matchAll(/\[\[([^\]|#]+)/g)) {
        const t = m[1].trim().toLowerCase();
        counts.set(t, (counts.get(t) ?? 0) + 1);
      }
    }
    const top = [...counts.entries()].sort((a, b) => b[1] - a[1]).slice(0, 5)
      .map(([t, c], i) => `${i + 1}. ${t} (${c})`).join("  ");
    await api.ui.notice(top || "링크가 없습니다");
  });
});
```

```json
{ "id": "link-stats", "name": "링크 통계", "version": "1.0.0", "author": "Crab Labs",
  "description": "링크를 많이 받은 노트 순위", "permissions": ["vault:read"] }
```

<aside>  
⚠️

명령 타임아웃은 10초입니다. 노트가 수천 개라면 결과를 `storage` 에 캐시하거나 여러 번에 나눠 처리하세요.

</aside>

## 5. 개발 루프와 디버깅

1. 앱의 **플러그인 관리** 화면에서 플러그인 폴더 경로를 확인합니다.
2. `<폴더>/word-count/manifest.json` 을 두고, `CRABNOTE_PLUGINS=<폴더> npm run dev` 로 main.js를 자동 빌드합니다.
3. 코드를 고친 뒤 명령 팔레트(`Ctrl/⌘+P`)에서 **플러그인 다시 불러오기**를 실행합니다.
4. 개발 빌드에서는 웹뷰 개발자 도구(우클릭 → 검사)가 열리며, Sources의 `plugin-word-count.js`(sourceURL)에서 중단점을 걸고 `console.log` 를 볼 수 있습니다.

<aside>  
🤖

**Antigravity 팁** — 플러그인 개발자도 에이전트를 활용할 수 있습니다: "_crabnote.d.ts를 참고해서, 선택한 목록을 가나다순으로 정렬하는 명령 플러그인을 만들어줘. 필요한 최소 권한만 manifest에 넣고_"

</aside>
