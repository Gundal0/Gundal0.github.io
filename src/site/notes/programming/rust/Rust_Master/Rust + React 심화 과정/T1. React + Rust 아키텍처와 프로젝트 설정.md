> 📖 민준: "React는 자신 있는데, 파일을 읽고 쓰는 건 브라우저에서 못 하잖아요?" 하린: "그래서 Rust가 있는 거예요. React는 화면만, 나머지는 전부 Rust가 책임져요."

## 🧩 문제 1 — 웹 기술로 데스크톱 앱을 만들되 세 OS에서 동일하게 동작해야 한다

## 💡 해결 1 — Tauri 2 + React 템플릿

<aside>  
⚛️

**React가 하는 일**

- 화면 구성과 상태 관리
- 에디터·미리보기·팔레트
- 플러그인 호스트(권한 검사)  
    </aside>

<aside>  
🦀

**Rust가 하는 일**

- 파일 읽기/쓰기, 경로 보안
- 링크 인덱스, 전문 검색, 감시
- 플러그인 설치·검증·저장소  
    </aside>

```bash
npm create tauri-app@latest crabnote-react -- --template react-ts --manager npm
cd crabnote-react
npm install
npm install zustand @uiw/react-codemirror @codemirror/lang-markdown @codemirror/autocomplete @codemirror/view \
            react-markdown remark-gfm
npm install -D vitest
npm run tauri add dialog      # 폴더·파일 선택
npm run tauri add opener      # 외부 링크를 기본 브라우저로 (템플릿에 이미 있을 수 있음)
```

<aside>  
📌

`create-tauri-app` 의 질문에 답하는 방식으로도 만들 수 있습니다(Frontend: TypeScript/JavaScript → React → TypeScript). OS별 사전 준비물은 심화 과정 A의 T1과 같습니다.

</aside>

## 🧩 문제 2 — 외부 JS 플러그인이 네트워크로 데이터를 빼돌리면 어쩌지?

## 💡 해결 2 — CSP를 처음부터 엄격하게

```json
// src-tauri/tauri.conf.json (발췌)
{
  "productName": "CrabNote React",
  "identifier": "com.crablabs.crabnote-react",
  "build": {
    "beforeDevCommand": "npm run dev",
    "devUrl": "<http://localhost:1420>",
    "beforeBuildCommand": "npm run build",
    "frontendDist": "../dist"
  },
  "app": {
    "windows": [{ "title": "CrabNote React", "width": 1280, "height": 820 }],
    "security": {
      "csp": "default-src 'self'; script-src 'self'; worker-src 'self' blob:; connect-src 'self' ipc: <http://ipc.localhost>; style-src 'self' 'unsafe-inline'; img-src 'self' asset: data:"
    }
  }
}
```

|지시어|의미|
|---|---|
|`worker-src 'self' blob:`|R4에서 플러그인을 Blob URL 워커로 실행하기 위해 필요|
|`connect-src 'self' ipc: ...`|앱 자신과 Tauri IPC만 허용 → 플러그인의 `fetch("<https://악성서버>")` 차단|
|`script-src 'self'`|워커 안에서도 `importScripts("https://...")` 로 외부 코드 로드 차단|

<aside>  
🔍

Blob URL로 만든 워커는 만든 문서의 CSP를 **상속**합니다. 그래서 메인 웹뷰의 CSP를 엄격하게 두면 플러그인 워커도 같은 제약을 받습니다. 네트워크가 필요한 플러그인은 나중에 **Rust를 거치는 프록시 API + 도메인 허용 목록 권한**으로 열어주는 것이 안전합니다.

</aside>

## 🧩 문제 3 — React 코드 곳곳에서 `invoke("문자열")` 을 부르면 관리가 안 된다

## 💡 해결 3 — 타입 있는 API 계층

```tsx
// src/lib/api.ts
import { invoke } from "@tauri-apps/api/core";

export type NoteMeta = { path: string; title: string };
export type Hit = { path: string; title: string; line: number; snippet: string };
export type JsPluginManifest = {
  id: string; name: string; version: string; author: string; description: string;
  min_app_version: string; permissions: string[]; main: string;
};
export type JsPlugin = { manifest: JsPluginManifest; code: string; enabled: boolean };

export const api = {
  // Vault
  openVault: (path: string) => invoke<NoteMeta[]>("open_vault", { path }),
  listNotes: () => invoke<NoteMeta[]>("list_notes"),
  read: (path: string) => invoke<string>("read_note", { path }),
  save: (path: string, text: string) => invoke<void>("save_note", { path, text }),
  openLink: (title: string) => invoke<NoteMeta>("open_link", { title }),
  rename: (path: string, newTitle: string) => invoke<[NoteMeta, number]>("rename_note", { path, newTitle }),
  backlinks: (title: string) => invoke<string[]>("backlinks", { title }),
  search: (query: string) => invoke<Hit[]>("search_notes", { query }),
  // Plugins
  listPlugins: () => invoke<JsPlugin[]>("list_js_plugins"),
  setPluginEnabled: (id: string, enabled: boolean) => invoke<void>("set_js_plugin_enabled", { id, enabled }),
  installPlugin: (zipPath: string, sha256?: string) => invoke<JsPluginManifest>("install_js_plugin", { zipPath, sha256 }),
  pluginStorageGet: (id: string) => invoke<unknown>("plugin_storage_get", { id }),
  pluginStorageSet: (id: string, value: unknown) => invoke<void>("plugin_storage_set", { id, value }),
  pluginsDir: () => invoke<string>("js_plugins_dir"),
};
```

<aside>  
🤖

**Antigravity 팁** — Rust 커맨드와 TS 타입이 어긋나지 않게 에이전트에게 점검을 맡기세요: "_src-tauri의 #[tauri::command] 시그니처와 src/lib/api.ts를 비교해서 인자 이름(camelCase)·반환 타입이 다른 곳을 표로 알려줘_". 규모가 커지면 `tauri-specta` 로 자동 생성하세요.

</aside>
