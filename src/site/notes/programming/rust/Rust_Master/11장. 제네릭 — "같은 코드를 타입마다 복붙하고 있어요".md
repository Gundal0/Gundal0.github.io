> 📖 **스토리** — 중급 과정의 첫날. 하린의 코드에는 `largest_i32`, `largest_f64`, `largest_char` 가 나란히 있었다. 페리스가 고개를 저었다. "로직은 하나인데 함수는 세 개구나."

## 🧩 문제 1 — 타입만 다른 중복 함수

```rust
fn largest_i32(list: &[i32]) -> i32 { /* ... */ }
fn largest_f64(list: &[f64]) -> f64 { /* ... */ }
```

## 💡 해결 1 — 제네릭 함수 + 트레이트 경계

```rust
fn largest<T: PartialOrd>(list: &[T]) -> Option<&T> {
    let mut iter = list.iter();
    let mut max = iter.next()?;
    for item in iter {
        if item > max {           // 비교하려면 T가 PartialOrd여야 함
            max = item;
        }
    }
    Some(max)
}

fn main() {
    println!("{:?}", largest(&[3, 9, 2]));          // Some(9)
    println!("{:?}", largest(&[1.5, 0.2]));         // Some(1.5)
    println!("{:?}", largest(&['가', '하', '나'])); // Some('하')
    println!("{:?}", largest::<u8>(&[]));           // None (터보피시 문법 ::<T>)
}
```

<aside>  
🔍

**단형화(monomorphization)** — 컴파일러는 사용된 타입마다 `largest::<i32>`, `largest::<f64>` 를 각각 생성합니다. 그래서 제네릭은 **런타임 비용이 0**입니다(대신 바이너리가 커질 수 있음).

</aside>

## 🧩 문제 2 — 좌표를 정수로도, 실수로도 저장하고 싶다

## 💡 해결 2 — 제네릭 구조체·열거형·impl

```rust
#[derive(Debug, Clone, Copy)]
struct Point<T> {
    x: T,
    y: T,
}

// 모든 T에 대해
impl<T: Copy> Point<T> {
    fn swap(self) -> Self { Point { x: self.y, y: self.x } }
}

// 특정 타입에만 있는 메서드
impl Point<f64> {
    fn distance_from_origin(&self) -> f64 {
        (self.x.powi(2) + self.y.powi(2)).sqrt()
    }
}

// 여러 타입 매개변수
#[derive(Debug)]
enum Either<L, R> {
    Left(L),
    Right(R),
}

fn main() {
    let p = Point { x: 3.0, y: 4.0 };
    println!("{}", p.distance_from_origin()); // 5
    println!("{:?}", Point { x: 1, y: 2 }.swap());
    let e: Either<i32, &str> = Either::Right("오류");
    println!("{e:?}");
}
```

## 🧩 문제 3 — 배열 길이까지 타입으로 표현하고 싶다

## 💡 해결 3 — const 제네릭

```rust
#[derive(Debug)]
struct RingBuffer<T, const N: usize> {
    data: [Option<T>; N],
    head: usize,
}

impl<T: Copy, const N: usize> RingBuffer<T, N> {
    fn new() -> Self { Self { data: [None; N], head: 0 } }
    fn push(&mut self, v: T) {
        self.data[self.head] = Some(v);
        self.head = (self.head + 1) % N;
    }
    fn capacity(&self) -> usize { N }
}

fn main() {
    let mut rb: RingBuffer<u32, 3> = RingBuffer::new();
    for i in 1..=5 { rb.push(i); }
    println!("{:?} (용량 {})", rb.data, rb.capacity()); // [Some(4), Some(5), Some(3)]
}
```

## 🔍 원리 — 경계를 쓰는 세 가지 방법

```rust
use std::fmt::{Debug, Display};

fn a<T: Display + Clone>(t: T) {}                     // 인라인
fn b<T, U>(t: T, u: U) where T: Display + Clone, U: Debug {} // where 절 (길 때)
fn c(t: impl Display) {}                               // impl Trait (간단할 때)
```
