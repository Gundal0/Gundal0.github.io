> 📖 **스토리** — 하린은 사내 공용 라이브러리를 맡게 됐다. 다른 팀이 쓰기 쉽고, **잘못 쓰면 컴파일이 안 되는** API를 만들어야 한다.

## 🧩 문제 1 — 제네릭으로 만들었더니 사용할 때마다 타입을 적어야 한다

## 💡 해결 1 — 연관 타입(Associated Type)

```rust
// 제네릭 버전: 한 타입이 Storage<String>, Storage<u32>... 여러 번 구현 가능 → 호출 시 모호
// trait Storage<T> { fn get(&self, key: &str) -> Option<T>; }

// 연관 타입 버전: 한 타입당 구현은 하나, Value는 구현자가 결정
trait Storage {
    type Value;
    fn get(&self, key: &str) -> Option<&Self::Value>;
}

struct Settings(std::collections::HashMap<String, String>);

impl Storage for Settings {
    type Value = String;
    fn get(&self, key: &str) -> Option<&String> { self.0.get(key) }
}

fn print_value<S: Storage>(s: &S, key: &str) where S::Value: std::fmt::Debug {
    println!("{key} = {:?}", s.get(key));
}
```

<aside>  
💡

**규칙**: "한 타입이 이 트레이트를 여러 방식으로 구현할 수 있나?" → 예: 제네릭(`From<T>`, `Add<Rhs>`), 아니오: 연관 타입(`Iterator::Item`, `Deref::Target`).

</aside>

## 🧩 문제 2 — 같은 이름의 메서드가 두 트레이트에 있다

## 💡 해결 2 — 완전 정규화 문법과 슈퍼트레이트

```rust
use std::fmt::Display;

trait Pilot { fn fly(&self) -> &str; }
trait Wizard { fn fly(&self) -> &str; }
struct Human;
impl Pilot for Human { fn fly(&self) -> &str { "기장입니다" } }
impl Wizard for Human { fn fly(&self) -> &str { "빗자루 타고 날기" } }

// 슈퍼트레이트: OutlinePrint를 구현하려면 Display도 구현해야 함
trait OutlinePrint: Display {
    fn outline(&self) -> String { format!("*** {self} ***") }
}
impl OutlinePrint for i32 {}

fn main() {
    let h = Human;
    println!("{}", Pilot::fly(&h));
    println!("{}", <Human as Wizard>::fly(&h));   // 완전 정규화 문법
    println!("{}", 7.outline());
}
```

## 🧩 문제 3 — 사용자 ID와 주문 ID가 둘 다 u64라 뒤바뀌어도 모른다

## 💡 해결 3 — newtype과 타입 상태(Typestate) 패턴

```rust
use std::marker::PhantomData;

#[derive(Debug, Clone, Copy, PartialEq)] struct UserId(u64);
#[derive(Debug, Clone, Copy, PartialEq)] struct OrderId(u64);
fn cancel(order: OrderId, by: UserId) { println!("{order:?} by {by:?}"); }
// cancel(UserId(1), OrderId(2)); ❌ 컴파일 오류

// 타입 상태: 상태를 타입 매개변수로 표현 → 잘못된 순서의 호출을 컴파일 단계에서 차단
struct Draft;
struct Published;
struct Post<State> { body: String, _state: PhantomData<State> }

impl Post<Draft> {
    fn new(body: &str) -> Self { Post { body: body.into(), _state: PhantomData } }
    fn publish(self) -> Post<Published> { Post { body: self.body, _state: PhantomData } }
}
impl Post<Published> {
    fn url(&self) -> String { format!("/posts/{}", self.body.len()) }
}

fn main() {
    cancel(OrderId(10), UserId(1));
    let draft = Post::new("안녕하세요");
    // draft.url();  ❌ 초안에는 url 메서드가 없음
    let post = draft.publish();
    println!("{}", post.url());
}
```

## 🔍 고급 타입 모음

### 🏷️ 타입 별칭 (type alias)

```rust
type Result<T> = std::result::Result<T, MyError>;   // 라이브러리에서 자주 보는 패턴
type Callback = Box<dyn Fn(&str) + Send + 'static>;
```

별칭은 새 타입이 아니라 같은 타입의 다른 이름입니다(newtype과의 차이).

### ❗ never 타입 `!`

```rust
fn fail(msg: &str) -> ! { panic!("{msg}") }

let n: u32 = match "5".parse() {
    Ok(v) => v,
    Err(_) => continue_or_fail(),  // ! 는 어떤 타입으로도 강제 변환됨
};
fn continue_or_fail() -> ! { std::process::exit(1) }
```

`panic!`, `loop {}`, `continue`, `break`, `return`, `process::exit` 의 타입이 `!` 입니다.

### 📏 동적 크기 타입(DST)과 `?Sized`

`str`, `[T]`, `dyn Trait` 는 컴파일 시점에 크기를 모르는 타입이라 항상 포인터 뒤(`&str`, `Box<[T]>`, `&dyn Trait`)에만 있을 수 있습니다. 제네릭은 기본적으로 `T: Sized` 라서, DST도 받으려면 경계를 풀어야 합니다.

```rust
fn show<T: ?Sized + std::fmt::Debug>(t: &T) { println!("{t:?}"); }
show("str");          // T = str
show(&[1, 2][..]);    // T = [i32]
```

### 🧬 기본 타입 매개변수와 GAT

```rust
// 기본 타입 매개변수: Add<Rhs = Self>
impl std::ops::Add<u32> for Meters { type Output = Meters; fn add(self, r: u32) -> Meters { Meters(self.0 + r as f64) } }
struct Meters(f64);

// GAT(Generic Associated Types): 연관 타입에 라이프타임/제네릭 매개변수
trait LendingIter {
    type Item<'a> where Self: 'a;
    fn next<'a>(&'a mut self) -> Option<Self::Item<'a>>;
}
```

### 🎯 dyn 호환성(object safety)

`dyn Trait` 으로 쓰려면 트레이트의 메서드가 (1) 제네릭 타입 매개변수가 없고 (2) `Self` 를 값으로 반환하지 않아야 합니다. 예외로 두고 싶은 메서드에는 `where Self: Sized` 를 붙이세요.

```rust
trait Plugin {
    fn name(&self) -> String;
    fn boxed_clone(&self) -> Box<dyn Plugin>;
    fn new_default() -> Self where Self: Sized;  // dyn에서는 제외됨
}
```
