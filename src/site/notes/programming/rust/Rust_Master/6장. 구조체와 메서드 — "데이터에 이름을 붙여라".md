> 📖 **스토리** — 회원 정보를 `(String, String, u32, bool)` 튜플로 들고 다니던 하린은 `user.2` 가 나이인지 포인트인지 헷갈려 버그를 냈다.

## 🧩 문제 1 — 튜플은 의미를 말해주지 않는다

## 💡 해결 1 — 구조체(struct)

```rust
#[derive(Debug, Clone, PartialEq)]
struct User {
    name: String,
    email: String,
    points: u32,
    active: bool,
}

fn main() {
    let name = String::from("하린");
    let mut harin = User {
        name,                                 // 필드 초기화 축약
        email: "harin@crab.dev".into(),
        points: 0,
        active: true,
    };
    harin.points += 100;                      // 구조체 전체가 mut여야 함

    let ferris = User {
        name: "페리스".into(),
        email: "ferris@crab.dev".into(),
        ..harin.clone()                       // 나머지 필드는 harin에서 가져옴(구조체 갱신 문법)
    };

    println!("{harin:#?}");
    println!("{} / {}", ferris.name, ferris.points); // 페리스 / 100
}
```

### 튜플 구조체와 유닛 구조체

```rust
struct Meters(f64);          // 튜플 구조체: 단위를 타입으로 구분 (newtype 패턴)

struct Marker;               // 유닛 구조체: 데이터 없이 타입만 필요할 때

// speed(Seconds(3.0), Meters(10.0)); ← 순서를 바꾸면 컴파일 오류! 👍
```

## 🧩 문제 2 — 구조체를 다루는 함수가 여기저기 흩어져 있다

## 💡 해결 2 — `impl` 블록과 메서드

```rust
#[derive(Debug)]
struct Rect { w: f64, h: f64 }

impl Rect {
    // 연관 함수(associated function): self가 없음. 보통 생성자로 사용
    fn new(w: f64, h: f64) -> Self {
        Self { w, h }
    }
    fn square(size: f64) -> Self {
        Self::new(size, size)
    }

    // &self: 읽기 전용 메서드
    fn area(&self) -> f64 { self.w * self.h }
    fn can_hold(&self, other: &Rect) -> bool { self.w > other.w && self.h > other.h }

    // &mut self: 수정 메서드
    fn scale(&mut self, k: f64) { self.w *= k; self.h *= k; }

    // self: 소유권을 가져가는 메서드 (변환·소비)
    fn into_tuple(self) -> (f64, f64) { (self.w, self.h) }
}

fn main() {
    let mut r = Rect::new(3.0, 4.0);
    r.scale(2.0);
    println!("넓이 {}, 정사각형을 품음? {}", r.area(), r.can_hold(&Rect::square(5.0)));
    let (w, h) = r.into_tuple();     // 이후 r은 사용 불가
    println!("{w} x {h}");
}
```

|첫 매개변수|의미|호출 후 원본|
|---|---|---|
|`&self`|빌려서 읽기|그대로 사용 가능|
|`&mut self`|빌려서 수정|사용 가능(변수가 `mut` 여야 함)|
|`self`|소유권 이동|사용 불가 (Copy 타입 제외)|
|(없음)|연관 함수, `Type::f()` 로 호출|-|

## 🧩 문제 3 — 인스턴스를 만들 때 선택 옵션이 너무 많다

## 💡 해결 3 — `Default` 와 빌더 패턴

```rust
#[derive(Debug, Default)]
struct ServerConfig {
    host: String,
    port: u16,
    workers: usize,
    verbose: bool,
}

struct ServerConfigBuilder { cfg: ServerConfig }

impl ServerConfigBuilder {
    fn new() -> Self {
        Self { cfg: ServerConfig { host: "127.0.0.1".into(), port: 8080, workers: 4, ..Default::default() } }
    }
    fn port(mut self, port: u16) -> Self { self.cfg.port = port; self }
    fn verbose(mut self, v: bool) -> Self { self.cfg.verbose = v; self }
    fn build(self) -> ServerConfig { self.cfg }
}

fn main() {
    let cfg = ServerConfigBuilder::new().port(3000).verbose(true).build();
    println!("{cfg:?}");
}
```

- Q1. `BankAccount { owner, balance }` 구조체에 `deposit`, `withdraw`(잔액 부족 시 false 반환) 메서드를 구현하세요.
    
    ```rust
    struct BankAccount { owner: String, balance: u64 }
    
    impl BankAccount {
        fn deposit(&mut self, amount: u64) { self.balance += amount; }
        fn withdraw(&mut self, amount: u64) -> bool {
            if self.balance < amount { return false; }
            self.balance -= amount;
            true
        }
    }
    ```
