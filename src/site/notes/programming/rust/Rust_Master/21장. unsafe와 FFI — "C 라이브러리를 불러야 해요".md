> 📖 **스토리** — 20년 된 C 라이브러리(암호화 모듈)를 Rust에서 써야 하고, 반대로 Rust로 만든 고속 파서를 Python·C 팀에 제공해야 한다. 페리스: "unsafe는 '안전하지 않은 코드'가 아니라 '**컴파일러 대신 내가 안전을 보증하는 코드**'야."

## 🔍 원리 — unsafe가 허용하는 5가지

<aside>  
☢️

1. 원시 포인터(`*const T`, `*mut T`) 역참조
2. `unsafe fn` / `unsafe extern` 함수 호출
3. `static mut` 접근·수정
4. `unsafe trait` 구현 (예: `Send`, `Sync` 수동 구현)
5. `union` 필드 접근

unsafe 블록 안에서도 빌림 검사기는 꺼지지 않습니다. 위 5가지만 추가로 허용됩니다.

</aside>

## 🧩 문제 1 — 한 슬라이스를 두 개의 가변 조각으로 나누고 싶다

빌림 검사기는 "같은 슬라이스에 `&mut` 가 두 개"라고만 보고 거부합니다. 하지만 두 조각이 겹치지 않는다는 것을 우리는 압니다.

## 💡 해결 1 — 안전한 추상화 안에 unsafe 감추기

```rust
use std::slice;

/// 표준 라이브러리의 split_at_mut을 직접 구현해 본다.
fn split_at_mut(values: &mut [i32], mid: usize) -> (&mut [i32], &mut [i32]) {
    let len = values.len();
    assert!(mid <= len);                    // ⭐ 안전 조건을 먼저 검사
    let ptr = values.as_mut_ptr();

    // SAFETY: mid <= len 이므로 두 영역 [0, mid), [mid, len)은 유효하고 겹치지 않는다.
    unsafe {
        (
            slice::from_raw_parts_mut(ptr, mid),
            slice::from_raw_parts_mut(ptr.add(mid), len - mid),
        )
    }
}

fn main() {
    let mut v = [1, 2, 3, 4, 5];
    let (a, b) = split_at_mut(&mut v, 2);
    a[0] = 100;
    b[0] = 300;
    println!("{v:?}"); // [100, 2, 300, 4, 5]
}
```

<aside>  
💡

**당연한 규칙**: unsafe 블록에는 항상 `// SAFETY:` 주석으로 왜 안전한지 적고, 외부에는 **안전한 함수**로만 노출하세요. `cargo +nightly miri test` 로 미정의 동작을 검사할 수 있습니다.

</aside>

## 🧩 문제 2 — C 함수를 Rust에서 호출하고 싶다

## 💡 해결 2 — `unsafe extern "C"` 블록 (2024 에디션 문법)

```c
// csrc/checksum.c
#include <stdint.h>
#include <stddef.h>

uint32_t checksum(const uint8_t* data, size_t len) {
    uint32_t sum = 0;
    for (size_t i = 0; i < len; i++) sum = sum * 31 + data[i];
    return sum;
}
```

```toml
# Cargo.toml
[build-dependencies]
cc = "1"
```

```rust
// build.rs — 빌드 전에 C 코드를 컴파일해 링크 (Windows/macOS/Linux 모두 동작)
fn main() {
    cc::Build::new().file("csrc/checksum.c").compile("checksum");
}
```

```rust
// src/main.rs
use std::ffi::{CStr, CString};
use std::os::raw::c_char;

unsafe extern "C" {
    fn checksum(data: *const u8, len: usize) -> u32;
    fn strlen(s: *const c_char) -> usize;          // C 표준 라이브러리
}

/// 안전한 래퍼: 호출자는 unsafe를 몰라도 된다
fn safe_checksum(data: &[u8]) -> u32 {
    // SAFETY: data는 len 바이트만큼 유효한 슬라이스다.
    unsafe { checksum(data.as_ptr(), data.len()) }
}

fn main() {
    println!("checksum = {}", safe_checksum(b"crab"));

    let c = CString::new("하린").unwrap();          // Rust → C 문자열 (끝에 \0)
    let n = unsafe { strlen(c.as_ptr()) };
    let back: &CStr = c.as_c_str();                  // C → Rust
    println!("{n} bytes, {:?}", back.to_str());
}
```

## 🧩 문제 3 — Rust 함수를 C·Python에서 부르고 싶다

## 💡 해결 3 — `#[unsafe(no_mangle)] extern "C"` + cdylib

```toml
[lib]
crate-type = ["cdylib"]   # .dll / .dylib / .so 생성
```

```rust
// src/lib.rs
#[unsafe(no_mangle)]                         // 2024 에디션: no_mangle은 unsafe 속성
pub extern "C" fn count_words(text: *const std::os::raw::c_char) -> u32 {
    if text.is_null() { return 0; }
    // SAFETY: 호출자는 NUL로 끝나는 유효한 문자열을 넘겨야 한다(문서화된 계약).
    let s = unsafe { std::ffi::CStr::from_ptr(text) };
    s.to_str().map(|t| t.split_whitespace().count() as u32).unwrap_or(0)
}
```

```python
# Python에서 호출 (ctypes)
import ctypes, sys
lib_name = {"win32": "wordcount.dll", "darwin": "libwordcount.dylib"}.get(sys.platform, "libwordcount.so")
lib = ctypes.CDLL(f"target/release/{lib_name}")
lib.count_words.argtypes = [ctypes.c_char_p]
print(lib.count_words("hello rust world".encode()))  # 3
```

<aside>  
📦

실무 도구: **bindgen**(C 헤더 → Rust 바인딩 자동 생성), **cbindgen**(Rust → C 헤더), **PyO3**(Python 확장 모듈), **UniFFI**(Kotlin·Swift 바인딩 — P4 모바일 편에서 사용), **wasm-bindgen**(JavaScript).

</aside>

## 🔍 기타 unsafe 기능

```rust
// static mut: 가능하면 AtomicXxx 나 OnceLock/Mutex를 쓰세요
use std::sync::OnceLock;
static CONFIG: OnceLock<String> = OnceLock::new();
fn config() -> &'static str { CONFIG.get_or_init(|| "prod".to_string()) }

// union: C 구조체와의 호환성을 위해 존재
#[repr(C)]
union IntOrFloat { i: u32, f: f32 }
fn bits() -> u32 { let u = IntOrFloat { f: 1.0 }; unsafe { u.i } }

// unsafe trait
unsafe trait Zeroable {}
unsafe impl Zeroable for u32 {}
```
