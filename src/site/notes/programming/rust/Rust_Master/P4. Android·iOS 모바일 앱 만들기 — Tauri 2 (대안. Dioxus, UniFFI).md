## 🧩 문제 1 — UI(JavaScript)에서 Rust 함수를 어떻게 부르지?

## 💡 해결 1 — `#[tauri::command]` 와 관리 상태(State)

```rust
// src-tauri/src/lib.rs
use serde::Serialize;
use std::sync::Mutex;
use tauri::State;

#[derive(Clone, Serialize)]
struct Todo {
    id: u32,
    title: String,
    done: bool,
}

#[derive(Default)]
struct AppState {
    todos: Mutex<Vec<Todo>>,      // 여러 커맨드가 동시에 호출될 수 있으므로 Mutex (17장)
    next_id: Mutex<u32>,
}

#[tauri::command]
fn list_todos(state: State<'_, AppState>) -> Vec<Todo> {
    state.todos.lock().unwrap().clone()
}

#[tauri::command]
fn add_todo(title: String, state: State<'_, AppState>) -> Result<Vec<Todo>, String> {
    let title = title.trim();
    if title.is_empty() {
        return Err("할 일을 입력하세요".into());   // JS에서는 Promise reject로 받음
    }
    let mut id = state.next_id.lock().unwrap();
    *id += 1;
    let mut todos = state.todos.lock().unwrap();
    todos.push(Todo { id: *id, title: title.to_string(), done: false });
    Ok(todos.clone())
}

#[tauri::command]
fn toggle_todo(id: u32, state: State<'_, AppState>) -> Vec<Todo> {
    let mut todos = state.todos.lock().unwrap();
    if let Some(t) = todos.iter_mut().find(|t| t.id == id) {
        t.done = !t.done;
    }
    todos.clone()
}

#[tauri::command]
fn platform() -> String {
    // 조건부 컴파일로 플랫폼 표시 (P1에서 배운 #[cfg])
    if cfg!(target_os = "android") { "Android" }
    else if cfg!(target_os = "ios") { "iOS" }
    else if cfg!(target_os = "windows") { "Windows" }
    else if cfg!(target_os = "macos") { "macOS" }
    else { "Linux" }
    .to_string()
}

#[cfg_attr(mobile, tauri::mobile_entry_point)]   // 모바일에서는 이 함수가 앱 진입점
pub fn run() {
    tauri::Builder::default()
        .manage(AppState::default())
        .invoke_handler(tauri::generate_handler![list_todos, add_todo, toggle_todo, platform])
        .run(tauri::generate_context!())
        .expect("Tauri 앱 실행 실패");
}
```

```rust
// src-tauri/src/main.rs  (데스크톱 진입점 — 템플릿이 생성한 것과 거의 동일)
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")] // Windows 릴리스에서 콘솔 창 숨김

fn main() {
    crab_todo_lib::run()   // Cargo.toml [lib] name 과 일치해야 함
}
```

## 💡 해결 2 — `invoke()`

```html
<!-- index.html (body 부분) -->
<main class="container">
  <h1>🦀 CrabTodo <small id="platform"></small></h1>
  <form id="form">
    <input id="title" placeholder="할 일을 입력하세요" />
    <button type="submit">추가</button>
  </form>
  <p id="error" style="color:#e5484d"></p>
  <ul id="list"></ul>
</main>
<script type="module" src="/src/main.ts"></script>
```

```tsx
// src/main.ts
import { invoke } from "@tauri-apps/api/core";

type Todo = { id: number; title: string; done: boolean };

const list = document.querySelector<HTMLUListElement>("#list")!;
const input = document.querySelector<HTMLInputElement>("#title")!;
const error = document.querySelector<HTMLParagraphElement>("#error")!;

function render(todos: Todo[]) {
  list.innerHTML = "";
  for (const t of todos) {
    const li = document.createElement("li");
    li.textContent = `${t.done ? "✅" : "⬜"} ${t.title}`;   // textContent → XSS 안전
    li.onclick = async () => render(await invoke<Todo[]>("toggle_todo", { id: t.id }));
    list.appendChild(li);
  }
}

document.querySelector("#form")!.addEventListener("submit", async (e) => {
  e.preventDefault();
  try {
    render(await invoke<Todo[]>("add_todo", { title: input.value })); // Rust 인자 이름과 같은 키
    input.value = "";
    error.textContent = "";
  } catch (err) {
    error.textContent = String(err);    // Rust의 Err(String)
  }
});

document.querySelector("#platform")!.textContent = await invoke<string>("platform");
render(await invoke<Todo[]>("list_todos"));
```

## 2단계 — 모바일에서 실행하기

Android

```bash
npm run tauri android init     # src-tauri/gen/android 프로젝트 생성 (최초 1회)
npm run tauri android dev      # 에뮬레이터 또는 USB 연결된 기기에서 핫 리로드 실행
npm run tauri android build    # 릴리스 APK/AAB 생성
```

실제 기기는 _개발자 옵션 → USB 디버깅_을 켜고 연결합니다. Play 스토어 배포용 AAB는 서명(keystore)이 필요합니다.

iOS

```bash
npm run tauri ios init         # src-tauri/gen/apple Xcode 프로젝트 생성
npm run tauri ios dev          # 시뮬레이터 선택 후 실행
npm run tauri ios dev --open   # Xcode로 열어 서명·실기기 설정
npm run tauri ios build        # IPA 생성
```

덤: 데스크톱 배포

```bash
npm run tauri build
# Windows: .msi / .exe,  macOS: .app / .dmg,  Ubuntu: .deb / .AppImage
```

같은 `lib.rs` 가 다섯 플랫폼 모두에서 동작합니다.

## 💡 해결 3 — 앱 데이터 디렉터리에 JSON 저장

```rust
// lib.rs에 추가 — serde::Deserialize 도 derive 하세요
use tauri::{AppHandle, Manager};

fn data_file(app: &AppHandle) -> std::path::PathBuf {
    let dir = app.path().app_data_dir().expect("데이터 디렉터리 없음"); // Android/iOS 샌드박스 경로도 자동 처리
    std::fs::create_dir_all(&dir).ok();
    dir.join("todos.json")
}

#[tauri::command]
fn save_todos(app: AppHandle, state: State<'_, AppState>) -> Result<(), String> {
    let todos = state.todos.lock().unwrap();
    let json = serde_json::to_string(&*todos).map_err(|e| e.to_string())?;
    std::fs::write(data_file(&app), json).map_err(|e| e.to_string())
}
```

## 🔍 대안 2 — UniFFI: 네이티브 앱에 Rust 코어 넣기

```rust
// Rust 라이브러리 (crate-type = ["cdylib", "staticlib"]) — Kotlin/Swift 바인딩이 자동 생성됨
uniffi::setup_scaffolding!();

#[uniffi::export]
fn checksum(text: String) -> u32 {
    text.bytes().fold(0u32, |acc, b| acc.wrapping_mul(31).wrapping_add(b as u32))
}
```

```kotlin
// Android (Kotlin)에서
val c = checksum("crab")
```

```swift
// iOS (Swift)에서
let c = checksum(text: "crab")
```
