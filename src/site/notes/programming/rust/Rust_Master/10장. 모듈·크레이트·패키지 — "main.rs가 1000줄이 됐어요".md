> 📖 **스토리** — 어느덧 `main.rs` 하나에 모든 코드가 몰려 있었다. 동료가 같은 파일을 고치면 충돌이 났다. 페리스가 "방을 나눠"라고 했다.

## 🔍 원리 — 용어 정리

|용어|뜻|
|---|---|
|**패키지(package)**|`Cargo.toml` 을 가진 프로젝트 단위. 크레이트를 하나 이상 포함|
|**크레이트(crate)**|컴파일 단위. 바이너리(`src/main.rs`) 또는 라이브러리(`src/lib.rs`)|
|**모듈(module)**|크레이트 안의 이름 공간. `mod` 로 선언, 공개 범위를 제어|
|**경로(path)**|`crate::shop::cart::Cart` 처럼 항목을 가리키는 이름|
|**워크스페이스**|여러 패키지를 하나의 `Cargo.lock`·`target` 으로 함께 관리|

## 🧩 문제 1 — 코드를 파일로 나누고 싶다

## 💡 해결 1 — 파일 = 모듈

```
shop/
├── Cargo.toml
└── src/
    ├── main.rs          # 바이너리 크레이트 (얼굴)
    ├── lib.rs           # 라이브러리 크레이트 (두뇌)
    ├── cart.rs          # mod cart
    └── payment/
        ├── mod.rs       # mod payment  (또는 src/payment.rs)
        └── card.rs      # mod payment::card
```

```rust
// src/lib.rs
pub mod cart;          // cart.rs 를 모듈로 포함
pub mod payment;       // payment/mod.rs

pub use cart::Cart;    // 재노출(re-export): shop::Cart 로 바로 쓸 수 있게
```

```rust
// src/cart.rs
#[derive(Debug, Default)]
pub struct Cart {
    pub items: Vec<(String, u32)>, // pub 필드
    discount: u32,                  // 비공개 필드: 모듈 밖에서 접근 불가
}

impl Cart {
    pub fn add(&mut self, name: &str, price: u32) {
        self.items.push((name.to_string(), price));
    }
    pub fn total(&self) -> u32 {
        let sum: u32 = self.items.iter().map(|(_, p)| p).sum();
        sum.saturating_sub(self.discount)
    }
    pub fn apply_coupon(&mut self, code: &str) {
        self.discount = crate::payment::card::coupon_value(code); // 절대 경로
    }
}
```

```rust
// src/payment/mod.rs
pub mod card;

// src/payment/card.rs
pub fn coupon_value(code: &str) -> u32 {
    if code == "CRAB10" { 1000 } else { 0 }
}

pub(crate) fn internal_helper() {}   // 같은 크레이트 안에서만 공개
```

```rust
// src/main.rs
use shop::Cart;        // 패키지 이름으로 라이브러리 크레이트를 참조

fn main() {
    let mut cart = Cart::default();
    cart.add("키보드", 50_000);
    cart.apply_coupon("CRAB10");
    println!("합계: {}원", cart.total());
}
```

## 🔍 공개 범위와 use 문법

|표기|공개 범위|
|---|---|
|(없음)|현재 모듈과 그 하위만|
|`pub`|어디서나|
|`pub(crate)`|현재 크레이트 안|
|`pub(super)`|부모 모듈까지|
|`pub(in crate::a)`|지정한 경로까지|

```rust
use std::collections::{HashMap, HashSet};   // 중첩 경로
use std::io::{self, Write};                  // self 포함
use std::fmt::Result as FmtResult;           // 별칭
use super::helper;                           // 부모 모듈
use self::inner::Thing;                      // 현재 모듈
```

## 🧩 문제 2 — 외부 라이브러리를 쓰고 싶다

## 💡 해결 2 — [crates.io](http://crates.io)와 `cargo add`

```bash
cargo add rand              # 최신 버전 추가
cargo add serde --features derive
cargo add tokio@1 --features full
cargo tree                  # 의존성 트리 보기
cargo update                # Cargo.lock 갱신
```

```toml
[dependencies]
rand = "0.9"          # ^0.9 → 0.9.x 중 최신 (SemVer 호환)
serde = { version = "1", features = ["derive"] }
my_utils = { path = "../my_utils" }        # 로컬 크레이트

[dev-dependencies]    # 테스트에서만 사용
pretty_assertions = "1"

[features]            # 선택적 기능 플래그
default = []
fancy = []
```

## 🧩 문제 3 — 서버와 CLI가 같은 코드를 공유해야 한다

## 💡 해결 3 — Cargo 워크스페이스

```toml
# 루트 Cargo.toml
[workspace]
members = ["shared", "cli", "server"]   # ⚠️ 'core'는 표준 크레이트 이름과 겹치므로 피하세요
resolver = "3"

[workspace.dependencies]
serde = { version = "1", features = ["derive"] }
```

```toml
# cli/Cargo.toml
[dependencies]
shared = { path = "../shared" }
serde = { workspace = true }
```

```bash
cargo run -p cli
cargo test --workspace
```
