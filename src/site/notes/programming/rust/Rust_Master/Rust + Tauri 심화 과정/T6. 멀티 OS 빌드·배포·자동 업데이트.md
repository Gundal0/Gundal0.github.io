> 📖 출시 일주일 전. 하린의 맥북에서는 잘 돌지만, 고객의 Windows 노트북과 Ubuntu 워크스테이션에서도 설치·실행·업데이트가 돼야 한다. 기본 플러그인도 함께 넣어야 한다.

## 🧩 문제 1 — 기본 플러그인을 설치 파일에 포함하고 싶다

## 💡 해결 1 — bundle resources + 최초 실행 시 복사

```json
// src-tauri/tauri.conf.json
{
  "bundle": {
    "active": true,
    "targets": "all",
    "icon": ["icons/32x32.png", "icons/128x128.png", "icons/icon.icns", "icons/icon.ico"],
    "resources": { "../example-plugins/dist/": "default-plugins/" },
    "category": "Productivity",
    "shortDescription": "플러그인을 지원하는 마크다운 노트"
  }
}
```

```rust
// src-tauri/src/lib.rs 의 setup 안에서, load_all 전에 호출
fn install_default_plugins(app: &tauri::App, plugins_dir: &std::path::Path) -> std::io::Result<()> {
    use tauri::Manager;
    let src = match app.path().resource_dir() { Ok(d) => d.join("default-plugins"), Err(_) => return Ok(()) };
    let Ok(entries) = std::fs::read_dir(&src) else { return Ok(()) };
    for entry in entries.flatten().filter(|e| e.path().is_dir()) {
        let dst = plugins_dir.join(entry.file_name());
        if dst.exists() { continue; }                   // 사용자가 지운/수정한 플러그인은 덮어쓰지 않음
        std::fs::create_dir_all(&dst)?;
        for f in std::fs::read_dir(entry.path())?.flatten() {
            std::fs::copy(f.path(), dst.join(f.file_name()))?;
        }
    }
    Ok(())
}
```

```bash
# example-plugins/build.sh — 샘플 플러그인을 dist/<id>/ 로 모으기
for p in frontmatter toc; do
  (cd $p && cargo build --release --target wasm32-unknown-unknown)
  mkdir -p dist/$p
  cp $p/target/wasm32-unknown-unknown/release/$p.wasm dist/$p/plugin.wasm
  cp $p/plugin.json dist/$p/
done
```

## 🧩 문제 2 — 아이콘과 설치 파일을 OS별로 만들어야 한다

## 💡 해결 2 — Tauri 번들러

```bash
npm run tauri icon ./app-icon.png     # 1024x1024 PNG 하나로 모든 OS 아이콘 생성
npm run tauri build
```

|OS|생성물 (src-tauri/target/release/bundle/)|배포 전 필수|
|---|---|---|
|🪟 Windows|`msi/*.msi`, `nsis/*-setup.exe`|코드 서명 인증서(없으면 SmartScreen 경고)|
|🍎 macOS|`macos/*.app`, `dmg/*.dmg`|Apple Developer ID 서명 + 공증(notarization)|
|🐧 Ubuntu|`deb/*.deb`, `appimage/*.AppImage`, `rpm/*.rpm`|없음 (선택: GPG 서명)|

## 🧩 문제 3 — 세 OS를 모두 가지고 있지 않다

## 💡 해결 3 — GitHub Actions + tauri-action

```yaml
# .github/workflows/release.yml
name: release
on:
  push:
    tags: ["v*"]

jobs:
  build:
    permissions:
      contents: write
    strategy:
      fail-fast: false
      matrix:
        include:
          - platform: macos-latest
            args: --target aarch64-apple-darwin
          - platform: macos-latest
            args: --target x86_64-apple-darwin
          - platform: ubuntu-22.04
            args: ""
          - platform: windows-latest
            args: ""
    runs-on: ${{ matrix.platform }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: lts/* }
      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.platform == 'macos-latest' && 'aarch64-apple-darwin,x86_64-apple-darwin' || '' }}
      - name: Ubuntu 의존성
        if: matrix.platform == 'ubuntu-22.04'
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
      - name: 코어 테스트 (세 OS 모두)
        run: cargo test -p crabnote-core
      - name: 기본 플러그인 빌드
        shell: bash
        run: rustup target add wasm32-unknown-unknown && cd example-plugins && bash build.sh
      - run: npm ci
      - uses: tauri-apps/tauri-action@v0
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          TAURI_SIGNING_PRIVATE_KEY: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY }}   # 업데이터 서명
          TAURI_SIGNING_PRIVATE_KEY_PASSWORD: ${{ secrets.TAURI_SIGNING_PRIVATE_KEY_PASSWORD }}
          # macOS 서명·공증: APPLE_CERTIFICATE, APPLE_CERTIFICATE_PASSWORD, APPLE_SIGNING_IDENTITY, APPLE_ID, APPLE_PASSWORD, APPLE_TEAM_ID
        with:
          tagName: v__VERSION__
          releaseName: "CrabNote Pro v__VERSION__"
          releaseDraft: true
          args: ${{ matrix.args }}
```

<aside>  
💡

`git tag v1.0.0 && git push --tags` 하면 네 가지 빌드가 동시에 돌고, 초안(draft) 릴리스에 모든 설치 파일이 올라갑니다. 검토 후 게시하세요.

</aside>

## 🧩 문제 4 — 사용자가 새 버전을 자동으로 받게 하고 싶다

## 💡 해결 4 — updater 플러그인

```bash
npm run tauri add updater
npm run tauri add process
npm run tauri signer generate -- -w ~/.tauri/crabnote.key   # 공개키는 설정에, 개인키는 CI 시크릿에
```

```json
// src-tauri/tauri.conf.json
{
  "bundle": { "createUpdaterArtifacts": true },
  "plugins": {
    "updater": {
      "pubkey": "생성된 공개키 내용",
      "endpoints": ["<https://github.com/crablabs/crabnote-pro/releases/latest/download/latest.json>"]
    }
  }
}
```

```tsx
// src/update.ts — 앱 시작 시 확인
import { check } from "@tauri-apps/plugin-updater";
import { relaunch } from "@tauri-apps/plugin-process";

export async function checkForUpdate() {
  const update = await check();
  if (!update) return;
  if (confirm(`새 버전 ${update.version}이 있습니다. 지금 업데이트할까요?`)) {
    await update.downloadAndInstall();
    await relaunch();
  }
}
```

<aside>  
⚠️

capability에 `updater:default`, `process:allow-restart` 를 추가해야 합니다. 업데이트 파일은 서명 검증을 통과해야만 설치되므로, **개인키를 잃어버리면 기존 사용자에게 업데이트를 보낼 수 없습니다.** 안전한 곳에 백업하세요.

</aside>
