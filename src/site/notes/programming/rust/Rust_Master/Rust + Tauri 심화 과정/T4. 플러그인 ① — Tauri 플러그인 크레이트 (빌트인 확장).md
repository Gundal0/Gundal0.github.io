> 📖 파트너사가 "문서 통계(단어 수, 읽는 시간) 기능을 만들어 주겠다"고 했다. 하린은 물었다. "그 코드를 우리 앱 코드에 섞지 않고, 독립된 모듈로 받을 수 없을까요?"

## 🔍 원리 — Tauri 플러그인이란?

Tauri 플러그인은 **Rust 커맨드 + JS 바인딩 + 권한 정의**를 하나로 묶은 크레이트입니다. `tauri-plugin-dialog`, `tauri-plugin-updater` 같은 공식 플러그인과 같은 구조이며, **앱과 함께 컴파일**됩니다.

|장점|한계|
|---|---|
|네이티브 성능, OS API·파일·네트워크 모두 사용, 모바일(Kotlin/Swift) 코드도 포함 가능, 권한(permission) 시스템 내장|사용자가 런타임에 설치할 수 없음(앱 재빌드 필요), 코드가 앱과 같은 권한으로 실행 → **신뢰할 수 있는 코드만**|

그래서 CrabNote Pro는 두 단계 전략을 씁니다. 우리와 파트너가 만드는 코어 기능 → **Tauri 플러그인(T4)**, 고객·커뮤니티가 만드는 기능 → **WASM 플러그인(T5)**.

## 🧩 문제 2 — 커맨드·상태·권한을 갖춘 실제 기능을 만들어야 한다

## 💡 해결 2 — 플러그인 구현

```rust
// crates/tauri-plugin-wordstats/src/models.rs
use serde::Serialize;

#[derive(Debug, Clone, Default, Serialize)]
pub struct WordStats {
    pub words: usize,
    pub chars: usize,
    pub headings: usize,
    pub links: usize,
    pub reading_minutes: f32,
}
```

```rust
// crates/tauri-plugin-wordstats/src/commands.rs
use crate::{StatsHistory, WordStats};
use tauri::{command, State};

/// 한국어는 분당 약 500자, 영어는 분당 약 230단어를 기준으로 읽는 시간을 추정
fn compute(text: &str) -> WordStats {
    let chars = text.chars().filter(|c| !c.is_whitespace()).count();
    let words = text.split_whitespace().count();
    let hangul = text.chars().filter(|c| ('가'..='힣').contains(c)).count();
    let reading_minutes = hangul as f32 / 500.0 + (words.saturating_sub(hangul / 3)) as f32 / 230.0;
    WordStats {
        words,
        chars,
        headings: text.lines().filter(|l| l.trim_start().starts_with('#')).count(),
        links: text.matches("[[").count(),
        reading_minutes: (reading_minutes * 10.0).round() / 10.0,
    }
}

#[command]
pub(crate) fn analyze(path: String, text: String, history: State<'_, StatsHistory>) -> WordStats {
    let stats = compute(&text);
    history.0.lock().unwrap().insert(path, stats.clone());   // 노트별 마지막 통계 기억
    stats
}

#[command]
pub(crate) fn vault_total(history: State<'_, StatsHistory>) -> WordStats {
    let h = history.0.lock().unwrap();
    h.values().fold(WordStats::default(), |mut acc, s| {
        acc.words += s.words;
        acc.chars += s.chars;
        acc.headings += s.headings;
        acc.links += s.links;
        acc.reading_minutes += s.reading_minutes;
        acc
    })
}

#[cfg(test)]
mod tests {
    #[test]
    fn counts_korean() {
        let s = super::compute("# 제목\n하린은 [[Rust]] 를 공부한다");
        assert_eq!((s.headings, s.links), (1, 1));
        assert!(s.chars > 0);
    }
}
```

```rust
// crates/tauri-plugin-wordstats/src/lib.rs
use std::{collections::HashMap, sync::Mutex};
use tauri::{
    plugin::{Builder, TauriPlugin},
    Manager, Runtime,
};

mod commands;
mod models;
pub use models::WordStats;

#[derive(Default)]
pub struct StatsHistory(pub(crate) Mutex<HashMap<String, WordStats>>);

/// 앱의 Rust 코드에서도 `app.wordstats()` 로 접근할 수 있게 해 주는 확장 트레이트
pub trait WordStatsExt<R: Runtime> {
    fn wordstats(&self) -> &StatsHistory;
}
impl<R: Runtime, T: Manager<R>> WordStatsExt<R> for T {
    fn wordstats(&self) -> &StatsHistory {
        self.state::<StatsHistory>().inner()
    }
}

pub fn init<R: Runtime>() -> TauriPlugin<R> {
    Builder::new("wordstats")                          // → JS에서 "plugin:wordstats|..."
        .invoke_handler(tauri::generate_handler![commands::analyze, commands::vault_total])
        .setup(|app, _api| {
            app.manage(StatsHistory::default());
            Ok(())
        })
        .build()
}
```

```rust
// crates/tauri-plugin-wordstats/build.rs — 커맨드별 allow-/deny- 권한을 자동 생성
const COMMANDS: &[&str] = &["analyze", "vault_total"];

fn main() {
    tauri_plugin::Builder::new(COMMANDS).build();
}
```

```toml
# crates/tauri-plugin-wordstats/permissions/default.toml
[default]
description = "문서 통계 분석을 허용합니다"
permissions = ["allow-analyze", "allow-vault-total"]
```

```tsx
// crates/tauri-plugin-wordstats/guest-js/index.ts
import { invoke } from "@tauri-apps/api/core";

export interface WordStats { words: number; chars: number; headings: number; links: number; reading_minutes: number }

export const analyze = (path: string, text: string) =>
  invoke<WordStats>("plugin:wordstats|analyze", { path, text });
export const vaultTotal = () => invoke<WordStats>("plugin:wordstats|vault_total");
```

## 🧩 문제 3 — 앱에 장착하고 권한을 주어야 한다

## 💡 해결 3 — 등록 + capability

```toml
# src-tauri/Cargo.toml
[dependencies]
tauri-plugin-wordstats = { path = "../crates/tauri-plugin-wordstats" }
```

```rust
// src-tauri/src/lib.rs 의 run()
tauri::Builder::default()
    .plugin(tauri_plugin_dialog::init())
    .plugin(tauri_plugin_wordstats::init())     // ⭐ 한 줄로 장착
    // ...
```

```json
// src-tauri/capabilities/default.json
{
  "identifier": "default",
  "windows": ["main"],
  "permissions": ["core:default", "dialog:default", "wordstats:default"]
}
```

```tsx
// src/main.ts — 저장 후 상태 표시줄에 통계 표시 (워크스페이스로 guest-js를 참조하거나 직접 invoke)
import { invoke } from "@tauri-apps/api/core";
const s = await invoke<{ words: number; reading_minutes: number }>("plugin:wordstats|analyze", { path: current.path, text: text() });
status(`${s.words} 단어 · 약 ${s.reading_minutes}분`);
```

<aside>  
⚠️

**함정** — capability에 `wordstats:default` 를 넣지 않으면 호출 시 `wordstats.analyze not allowed` 같은 에러가 납니다. Tauri 2는 **기본적으로 모든 플러그인 커맨드를 차단**하고, 앱이 명시적으로 허용한 것만 열어줍니다.

</aside>
