> 📖 페리스: "코드를 쓰기 전에 **경계**부터 그려. UI가 바뀌어도, 플러그인이 늘어도, OS가 달라도 흔들리지 않는 중심이 있어야 해."

## 🧩 문제 1 — P2(egui)의 코드는 UI와 로직이 섞여 있어 테스트·재사용이 어렵다

## 💡 해결 1 — Cargo 워크스페이스로 계층을 분리한다

```
crabnote-pro/
├── Cargo.toml                 # [workspace]
├── crates/
│   ├── crabnote-core/         # ⭐ 순수 Rust 도메인 (UI·Tauri 의존성 0)
│   └── tauri-plugin-wordstats/# T4 빌트인 Tauri 플러그인
├── src-tauri/                 # Tauri 앱 (커맨드, 상태, 플러그인 호스트)
├── src/                       # 프론트엔드 (TypeScript + CodeMirror)
├── plugin-sdk/                # 외부 개발자용 문서·타입·템플릿
└── example-plugins/           # T5 샘플 WASM 플러그인 (워크스페이스 밖에서 따로 빌드)
    ├── toc/
    └── frontmatter/
```

```toml
# Cargo.toml (루트)
[workspace]
members = ["crates/crabnote-core", "crates/tauri-plugin-wordstats", "src-tauri"]
exclude = ["example-plugins"]     # wasm 타깃으로 따로 빌드
resolver = "3"

[workspace.dependencies]
serde = { version = "1", features = ["derive"] }
serde_json = "1"
thiserror = "2"
```

<aside>  
💡

**의존성 방향 규칙**: `src-tauri → crabnote-core` 는 되지만 반대는 안 됩니다. core가 Tauri를 모르기 때문에 `cargo test -p crabnote-core` 가 GUI 없이 모든 OS의 CI에서 빠르게 돌고, 심화 과정 B(React)나 CLI 도구에서도 그대로 재사용됩니다.

</aside>

## 🧩 문제 2 — 세 OS의 개발 환경을 맞춰야 한다

## 💡 해결 2 — OS별 Tauri 사전 준비물

Windows

- Visual Studio C++ Build Tools (0장에서 설치)
- **WebView2** — Windows 10/11에는 기본 포함. 없으면 Microsoft 사이트에서 Evergreen Runtime 설치
- Node.js LTS

macOS

```bash
xcode-select --install
brew install node
```

웹뷰는 시스템의 WKWebView를 사용합니다.

Ubuntu

```bash
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

웹뷰는 WebKitGTK를 사용합니다.

<aside>  
⚠️

**함정 — 웹뷰가 OS마다 다르다**: Windows(Chromium 기반 WebView2), macOS(Safari 기반 WebKit), Linux(WebKitGTK). 최신 CSS·JS 기능을 쓸 때는 세 엔진 모두에서 테스트하세요. 파일 접근·경로 처리는 웹뷰가 아니라 **Rust에서** 하므로 OS 차이를 한 곳에서 흡수합니다.

</aside>

## 1단계 — 프로젝트 생성

```bash
npm create tauri-app@latest crabnote-pro
# Frontend: TypeScript / JavaScript → npm → Vanilla → TypeScript
cd crabnote-pro
npm install
npm install codemirror @codemirror/view @codemirror/lang-markdown @codemirror/autocomplete
npm run tauri add dialog          # 폴더 선택 대화상자 플러그인

# Rust 코어 크레이트
mkdir crates && cargo new --lib crates/crabnote-core
```

```toml
# src-tauri/Cargo.toml (발췌)
[dependencies]
crabnote-core = { path = "../crates/crabnote-core" }
tauri = { version = "2", features = [] }
tauri-plugin-dialog = "2"
serde = { workspace = true }
serde_json = { workspace = true }
notify = "8"
extism = "1"          # T5 WASM 플러그인 호스트
```

```json
// src-tauri/tauri.conf.json (발췌)
{
  "productName": "CrabNote Pro",
  "identifier": "com.crablabs.crabnote",
  "app": {
    "windows": [{ "title": "CrabNote Pro", "width": 1280, "height": 820 }],
    "security": {
      "csp": "default-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' asset: data:"
    }
  }
}
```

<aside>  
🔒

**CSP를 반드시 설정하세요.** 마크다운 미리보기는 사용자 문서를 HTML로 보여주므로, 악의적인 `<script>` 가 들어있는 노트를 열었을 때 실행되지 않도록 CSP와 HTML 정화(T3)를 함께 적용합니다.

</aside>

## 🔍 원리 — Tauri의 두 세계

|프론트엔드 (웹뷰)|백엔드 (Rust 코어 프로세스)|
|---|---|
|HTML/CSS/TS, 화면 담당|파일·OS·플러그인 담당|
|`invoke("cmd", args)` 로 요청|`#[tauri::command]` 로 응답|
|`listen("event")` 로 수신|`app.emit("event", payload)` 로 푸시|
|허용된 기능만 호출 가능|`capabilities/*.json` 으로 권한 제어|

<aside>  
🤖

**Antigravity 팁** — 워크스페이스가 커지면 에이전트에게 작업 범위를 분명히 주세요. 예: "_crates/crabnote-core 안에서만 작업하고, src-tauri는 건드리지 마. 끝나면 cargo test -p crabnote-core 결과를 보여줘_"

</aside>
