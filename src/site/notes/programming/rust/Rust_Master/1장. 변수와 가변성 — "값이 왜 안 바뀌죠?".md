> 📖 **스토리** — 첫 업무는 방문자 수를 세는 작은 프로그램이었다. Python에서 하던 대로 코드를 적자마자 빨간 밑줄이 그어졌다.

## 🧩 문제 1 — `cannot assign twice to immutable variable`

```rust
fn main() {
    let visitors = 0;
    visitors = visitors + 1; // ❌ error[E0384]
    println!("방문자: {visitors}");
}
```

## 💡 해결 1 — `mut` 를 붙인다

Rust의 변수는 **기본적으로 불변(immutable)**입니다. 바뀔 값이라면 명시적으로 `mut` 를 적습니다.

```rust
fn main() {
    let mut visitors = 0;
    visitors += 1;
    println!("방문자: {visitors}"); // 방문자: 1
}
```

<aside>  
🦀

**페리스**: "불변이 기본인 건 불편하라고 있는 게 아니야. 코드를 읽는 사람은 `mut` 가 없는 변수를 '절대 안 바뀌는 값'으로 믿고 읽을 수 있거든. 버그의 절반은 '누가 이 값을 바꿨지?'에서 시작돼."

</aside>

## 🧩 문제 2 — 절대 바뀌면 안 되는 값을 어디에 둘까?

최대 접속자 수처럼 프로그램 전체에서 쓰는 고정값이 필요했다.

## 💡 해결 2 — `const` 와 `static`

```rust
const MAX_VISITORS: u32 = 10_000;          // 컴파일 타임 상수, 타입 명시 필수
static SERVICE_NAME: &str = "Crab Labs";   // 프로그램 전체 기간 살아 있는 고정 주소의 값

fn main() {
    println!("{SERVICE_NAME}의 최대 접속자: {MAX_VISITORS}");
}
```

|구분|`let`|`const`|`static`|
|---|---|---|---|
|변경|`mut` 시 가능|불가|`static mut` 은 unsafe (사실상 금지)|
|값 결정 시점|실행 중|컴파일 중(사용처에 인라인)|컴파일 중(메모리 주소 1개)|
|이름 관례|`snake_case`|`SCREAMING_SNAKE_CASE`|`SCREAMING_SNAKE_CASE`|

## 🧩 문제 3 — 문자열로 받은 입력을 숫자로 바꾸려는데 이름이 고민된다

`input_str`, `input_num`... 이름이 자꾸 늘어난다.

## 💡 해결 3 — 섀도잉(Shadowing)

같은 이름으로 `let` 을 다시 쓰면 **새 변수**가 이전 변수를 가립니다. 타입을 바꿀 수도 있습니다.

```rust
fn main() {
    let count = "42";                         // &str
    let count: u32 = count.trim().parse().expect("숫자가 아닙니다"); // u32
    let count = count * 2;                    // 여전히 불변

    {
        let count = 0;                        // 안쪽 블록에서만 가림
        println!("블록 안: {count}");      // 0
    }
    println!("블록 밖: {count}");          // 84
}
```

<aside>  
⚠️

**함정** — `mut` 는 "같은 변수의 값을 바꿈(타입 고정)", 섀도잉은 "같은 이름의 새 변수를 만듦(타입 변경 가능)"입니다. `let mut s = "a"; s = 5;` 는 타입 오류입니다.

</aside>

## 🔍 원리 — 패턴으로 변수 선언하기

`let` 의 왼쪽은 사실 **패턴**입니다. 한 번에 여러 변수를 만들 수 있습니다.

```rust
let (x, mut y) = (1, 2);
y += x;
let _unused = 10;   // 밑줄로 시작하면 '안 쓴 변수' 경고를 끔
let _ = expensive(); // 값을 버림(즉시 drop)
```

## 🏋️ 연습 문제

- Q1. 다음 코드의 출력은? `let x = 5; let x = x + 1; { let x = x * 2; println!("{x}"); } println!("{x}");`
    
    `12` 그리고 `6`. 블록 안의 섀도잉은 블록을 벗어나면 사라집니다.
    
- Q2. `const` 에는 `String::from("a")` 를 넣을 수 없는 이유는?
    
    `const` 는 컴파일 타임에 값이 결정되어야 하지만 `String::from` 은 힙 메모리를 할당하는 런타임 함수이기 때문입니다. `const fn` 으로 표시된 함수만 상수 문맥에서 호출할 수 있습니다.
    
- Q3. (실습) 사용자에게 나이를 입력받아 10년 뒤 나이를 출력하세요.
    
    ```rust
    use std::io;
    
    fn main() {
        let mut age = String::new();
        io::stdin().read_line(&mut age).expect("입력 실패");
        let age: u32 = age.trim().parse().expect("숫자를 입력하세요");
        println!("10년 뒤: {}살", age + 10);
    }
    ```
