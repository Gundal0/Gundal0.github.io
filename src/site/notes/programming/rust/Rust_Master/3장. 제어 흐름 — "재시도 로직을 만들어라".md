> 📖 **스토리** — 서버 연결이 가끔 실패한다. 페리스가 말했다. "최대 5번까지 재시도하고, 성공하면 바로 멈추고, 몇 번 만에 성공했는지 알려줘."

## 🧩 문제 1 — 조건에 따라 다른 값을 변수에 넣고 싶다

## 💡 해결 1 — `if` 는 식이다

```rust
fn main() {
    let latency_ms = 180;

    let status = if latency_ms < 100 {
        "빠름"
    } else if latency_ms < 300 {
        "보통"
    } else {
        "느림"
    };   // 모든 가지의 타입이 같아야 한다

    println!("응답 속도: {status}");
}
```

<aside>  
⚠️

**함정** — 조건은 반드시 `bool` 이어야 합니다. `if count { }` 처럼 숫자를 넣으면 오류입니다. `if count != 0 { }` 으로 쓰세요.

</aside>

## 🧩 문제 2 — 성공할 때까지 반복하고 결과를 돌려받고 싶다

## 💡 해결 2 — `loop` + `break 값`

```rust
fn try_connect(attempt: u32) -> bool {
    attempt == 3   // 3번째 시도에 성공한다고 가정
}

fn main() {
    let mut attempt = 0;

    let result = loop {
        attempt += 1;
        if try_connect(attempt) {
            break Some(attempt);       // loop는 break로 값을 돌려줄 수 있다
        }
        if attempt == 5 {
            break None;
        }
        println!("{attempt}번째 실패, 재시도...");
    };

    match result {
        Some(n) => println!("✅ {n}번 만에 연결 성공"),
        None => println!("❌ 5번 모두 실패"),
    }
}
```

## 🧩 문제 3 — 중첩 루프에서 바깥 루프까지 한 번에 빠져나가고 싶다

## 💡 해결 3 — 루프 레이블

```rust
fn main() {
    let grid = [[1, 2, 3], [4, -1, 6], [7, 8, 9]];

    'rows: for (r, row) in grid.iter().enumerate() {
        for (c, &value) in row.iter().enumerate() {
            if value < 0 {
                println!("음수 발견: ({r}, {c})");
                break 'rows;            // 바깥 루프 종료
            }
            if value % 2 == 0 {
                continue;               // 현재 루프의 다음 반복
            }
            println!("홀수 {value}");
        }
    }
}
```

## 🔍 원리 — 반복문 3형제

```rust
// while: 조건이 참인 동안
let mut countdown = 3;
while countdown > 0 {
    println!("{countdown}...");
    countdown -= 1;
}

// for + 범위(Range)
for i in 0..3 { print!("{i} "); }        // 0 1 2   (끝 제외)
for i in 0..=3 { print!("{i} "); }       // 0 1 2 3 (끝 포함)
for i in (1..=3).rev() { print!("{i} "); } // 3 2 1
for i in (0..10).step_by(3) { print!("{i} "); } // 0 3 6 9

// for + 컨테이너 (가장 많이 씁니다)
let names = ["하린", "페리스"];
for name in names.iter() { println!("{name}"); }
```

|구문|언제|
|---|---|
|`loop`|무한 반복, 재시도, 값을 돌려받을 때|
|`while`|반복 횟수를 모르고 조건만 알 때|
|`for`|컨테이너·범위를 순회할 때 (인덱스 오류가 없어 가장 안전)|

## 🏋️ 연습 문제

- Q1. FizzBuzz: 1~30까지 3의 배수는 Fizz, 5의 배수는 Buzz, 둘 다면 FizzBuzz를 출력하세요.
    
    ```rust
    fn main() {
        for n in 1..=30 {
            let out = match (n % 3, n % 5) {
                (0, 0) => "FizzBuzz".to_string(),
                (0, _) => "Fizz".to_string(),
                (_, 0) => "Buzz".to_string(),
                _ => n.to_string(),
            };
            println!("{out}");
        }
    }
    ```
    
    `match` 는 7장에서 자세히 배웁니다.
