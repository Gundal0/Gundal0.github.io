## 🧩 문제 1 — HTML을 문자열로 이어 붙이면 오타와 XSS가 생긴다

## 💡 해결 1 — 타입 안전한 템플릿: Askama

Askama는 템플릿을 **컴파일 타임에 Rust 코드로 변환**합니다. 없는 필드를 쓰면 빌드가 실패하고, 변수는 기본적으로 HTML 이스케이프되어 XSS를 막습니다.

```html
<!-- templates/base.html -->
<!doctype html>
<html lang="ko">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <title>{% block title %}Crab Labs{% endblock %}</title>
  <link rel="stylesheet" href="/static/style.css" />
</head>
<body>
  <nav><a href="/">🦀 Crab Labs</a> · <a href="/blog">블로그</a></nav>
  <main>{% block content %}{% endblock %}</main>
  <footer>© 2026 Crab Labs · Rust로 만들었습니다</footer>
</body>
</html>
```

```html
<!-- templates/index.html -->
{% extends "base.html" %}
{% block content %}
<h1>안전하고 빠른 소프트웨어</h1>
<p>{{ tagline }}</p>
<h2>최근 글</h2>
<ul>
  {% for p in recent %}
  <li><a href="/blog/{{ p.slug }}">{{ p.title }}</a></li>
  {% endfor %}
</ul>
<h2>문의하기</h2>
<form method="post" action="/contact">
  <input name="name" placeholder="이름" required />
  <input name="email" type="email" placeholder="이메일" required />
  <textarea name="message" placeholder="문의 내용" required></textarea>
  <button>보내기</button>
</form>
{% endblock %}
```

```html
<!-- templates/post.html -->
{% extends "base.html" %}
{% block title %}{{ title }} · Crab Labs{% endblock %}
{% block content %}
<article>
  <h1>{{ title }}</h1>
  {{ body_html|safe }}   <!-- 우리가 만든 HTML이므로 safe 필터로 이스케이프 해제 -->
</article>
{% endblock %}
```

## 🧩 문제 2 — URL마다 다른 페이지를 보여주고, 없는 글은 404를 주고 싶다

## 💡 해결 2 — Axum 라우터와 추출기(Extractor)

```rust
// src/main.rs
use askama::Template;
use axum::{
    extract::{Form, Path},
    http::StatusCode,
    response::{Html, IntoResponse, Response},
    routing::{get, post},
    Router,
};
use pulldown_cmark::{html, Options, Parser};
use serde::Deserialize;
use tower_http::services::ServeDir;

// ---------- 도메인 ----------
struct PostMeta { slug: String, title: String }

fn list_posts() -> Vec<PostMeta> {
    let mut posts: Vec<PostMeta> = std::fs::read_dir("content/posts")
        .into_iter()
        .flatten()
        .filter_map(Result::ok)
        .filter_map(|e| {
            let slug = e.path().file_stem()?.to_str()?.to_string();
            let text = std::fs::read_to_string(e.path()).ok()?;
            let title = text.lines().next()?.trim_start_matches('#').trim().to_string();
            Some(PostMeta { slug, title })
        })
        .collect();
    posts.sort_by(|a, b| b.slug.cmp(&a.slug));
    posts
}

fn markdown_to_html(md: &str) -> String {
    let mut out = String::new();
    html::push_html(&mut out, Parser::new_ext(md, Options::all()));
    out
}

// ---------- 템플릿 ----------
#[derive(Template)] #[template(path = "index.html")]
struct IndexTpl { tagline: &'static str, recent: Vec<PostMeta> }

#[derive(Template)] #[template(path = "blog_list.html")]
struct BlogListTpl { posts: Vec<PostMeta> }

#[derive(Template)] #[template(path = "post.html")]
struct PostTpl { title: String, body_html: String }

#[derive(Template)] #[template(path = "thanks.html")]
struct ThanksTpl { name: String }

// ---------- 에러 → HTTP 응답 ----------
enum AppError { NotFound, Render(askama::Error) }

impl From<askama::Error> for AppError {
    fn from(e: askama::Error) -> Self { AppError::Render(e) }
}

impl IntoResponse for AppError {
    fn into_response(self) -> Response {
        match self {
            AppError::NotFound => (StatusCode::NOT_FOUND, Html("<h1>404 — 페이지를 찾을 수 없습니다</h1>")).into_response(),
            AppError::Render(e) => (StatusCode::INTERNAL_SERVER_ERROR, format!("렌더링 오류: {e}")).into_response(),
        }
    }
}

type Page = Result<Html<String>, AppError>;

// ---------- 핸들러 ----------
async fn index() -> Page {
    let recent = list_posts().into_iter().take(3).collect();
    Ok(Html(IndexTpl { tagline: "Rust로 만든 초고속 홈페이지입니다.", recent }.render()?))
}

async fn blog_list() -> Page {
    Ok(Html(BlogListTpl { posts: list_posts() }.render()?))
}

async fn post(Path(slug): Path<String>) -> Page {
    // 🔒 경로 조작(../../etc/passwd) 방지: 영문·숫자·하이픈만 허용
    if !slug.chars().all(|c| c.is_ascii_alphanumeric() || c == '-') {
        return Err(AppError::NotFound);
    }
    let md = tokio::fs::read_to_string(format!("content/posts/{slug}.md"))
        .await
        .map_err(|_| AppError::NotFound)?;
    let title = md.lines().next().unwrap_or(&slug).trim_start_matches('#').trim().to_string();
    Ok(Html(PostTpl { title, body_html: markdown_to_html(&md) }.render()?))
}

#[derive(Deserialize)]
struct Contact { name: String, email: String, message: String }

async fn contact(Form(c): Form<Contact>) -> Page {
    // 실제 서비스에서는 DB 저장(sqlx)이나 메일 발송을 합니다
    println!("📩 문의: {} <{}> {}자", c.name, c.email, c.message.chars().count());
    Ok(Html(ThanksTpl { name: c.name }.render()?))
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/", get(index))
        .route("/blog", get(blog_list))
        .route("/blog/{slug}", get(post))          // Axum 0.8 경로 문법: {param}
        .route("/contact", post(contact))
        .nest_service("/static", ServeDir::new("static"));

    let addr = std::env::var("ADDR").unwrap_or_else(|_| "0.0.0.0:3000".into());
    let listener = tokio::net::TcpListener::bind(&addr).await.expect("포트 바인드 실패");
    println!("🦀 http://{addr}");
    axum::serve(listener, app).await.unwrap();
}
```

## 🧩 문제 3 — 서버에 배포하고 싶다

## 💡 해결 3 — 멀티 스테이지 Docker 빌드

```docker
# Dockerfile
FROM rust:1 AS build
WORKDIR /app
COPY . .
RUN cargo build --release

FROM debian:bookworm-slim
WORKDIR /app
COPY --from=build /app/target/release/crab-site /app/crab-site
COPY templates ./templates
COPY content ./content
COPY static ./static
ENV ADDR=0.0.0.0:8080
EXPOSE 8080
CMD ["/app/crab-site"]
```

```bash
docker build -t crab-site .
docker run -p 8080:8080 crab-site
```

<aside>  
📐

템플릿은 컴파일 타임에 바이너리에 포함되므로 사실 `templates` 복사는 필요 없지만, `content` 와 `static` 은 런타임에 읽으므로 필요합니다. 이 이미지는 [Fly.io](http://Fly.io), Cloud Run, AWS ECS, 사내 서버 어디에서나 실행됩니다.
