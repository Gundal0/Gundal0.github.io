> 📖 P1 `crabmon` 을 터미널이 낯선 디자이너도 쓸 수 있게, 창이 뜨는 앱으로 만들어 달라는 요청이 왔다.

```bash
cargo add eframe
```

## 🔍 원리 — 즉시 모드(Immediate Mode) GUI

<aside>  
🏛️

**유지 모드 (일반 GUI)**

## 🧩 문제 — 입력·버튼·슬라이더·체크박스가 있는 창을 빠르게 만들고 싶다

## 💡 해결 — eframe 앱 뼈대

```rust
use eframe::egui;

fn main() -> eframe::Result {
    let options = eframe::NativeOptions {
        viewport: egui::ViewportBuilder::default().with_inner_size([420.0, 320.0]),
        ..Default::default()
    };
    eframe::run_native("Crab Widgets", options, Box::new(|_cc| Ok(Box::<App>::default())))
}

struct App {
    name: String,
    threshold: f32,
    dark: bool,
    clicks: u32,
    log: Vec<String>,
}

impl Default for App {
    fn default() -> Self {
        Self { name: "Harin".into(), threshold: 80.0, dark: true, clicks: 0, log: vec![] }
    }
}

impl eframe::App for App {
    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        ctx.set_visuals(if self.dark { egui::Visuals::dark() } else { egui::Visuals::light() });

        egui::CentralPanel::default().show(ctx, |ui| {
            ui.heading("🦀 Crab Widgets");
            ui.horizontal(|ui| {
                ui.label("Name:");
                ui.text_edit_singleline(&mut self.name);   // &mut 로 상태를 직접 연결
            });
            ui.add(egui::Slider::new(&mut self.threshold, 0.0..=100.0).text("Alert %"));
            ui.checkbox(&mut self.dark, "Dark mode");

            if ui.button(format!("Clicked {} times", self.clicks)).clicked() {
                self.clicks += 1;
                self.log.push(format!("{} clicked (threshold {:.0}%)", self.name, self.threshold));
            }

            ui.separator();
            egui::ScrollArea::vertical().max_height(120.0).show(ui, |ui| {
                for line in self.log.iter().rev() {
                    ui.monospace(line);
                }
            });
        });
    }
}
```

<aside>  
⚠️

**한글 표시**: egui 기본 폰트에는 한글이 없어 □로 보입니다. P2의 `install_korean_font()` 처럼 Noto Sans KR 등을 `FontDefinitions` 에 등록하세요. 또 egui는 버전별 API 변화가 있으므로 [docs.rs](http://docs.rs)의 같은 버전 예제를 참고하세요.

</aside>
