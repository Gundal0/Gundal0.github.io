> 📖 18장에서 async의 원리를 배운 하린에게 새 임무가 떨어졌다. IoT 센서 수천 대가 동시에 접속하는 **TCP 채팅형 중계 서버**를 만들어야 한다.

```bash
cargo add tokio --features full
```

## 🧩 문제 — 접속한 모든 클라이언트에게 메시지를 중계해야 한다

## 💡 해결 — `TcpListener` + 연결당 태스크 + `broadcast` 채널

```rust
use tokio::io::{AsyncBufReadExt, AsyncWriteExt, BufReader};
use tokio::net::TcpListener;
use tokio::sync::broadcast;

#[tokio::main]
async fn main() -> std::io::Result<()> {
    let listener = TcpListener::bind("0.0.0.0:7878").await?;
    let (tx, _) = broadcast::channel::<(std::net::SocketAddr, String)>(1024);
    println!("📡 중계 서버 :7878");

    loop {
        let (socket, addr) = listener.accept().await?;
        let tx = tx.clone();
        let mut rx = tx.subscribe();

        tokio::spawn(async move {                       // 연결마다 가벼운 태스크 하나
            let (reader, mut writer) = socket.into_split();
            let mut lines = BufReader::new(reader).lines();

            loop {
                tokio::select! {
                    line = lines.next_line() => match line {
                        Ok(Some(text)) => { let _ = tx.send((addr, text)); }
                        _ => break,                       // 연결 종료 또는 오류
                    },
                    msg = rx.recv() => {
                        if let Ok((from, text)) = msg {
                            if from != addr {
                                let line = format!("[{from}] {text}\n");
                                if writer.write_all(line.as_bytes()).await.is_err() { break; }
                            }
                        }
                    }
                }
            }
            println!("👋 {addr} 종료");
        });
    }
}
```

```bash
# 터미널 여러 개에서 접속해 테스트 (Windows는 WSL 또는 ncat)
nc localhost 7878
```

## 📋 tokio 도구 지도

|모듈|주요 기능|
|---|---|
|`tokio::spawn`, `task::JoinSet`, `task::spawn_blocking`|태스크 실행|
|`tokio::sync::{mpsc, oneshot, broadcast, watch}`|비동기 채널|
|`tokio::sync::{Mutex, RwLock, Semaphore, Notify}`|비동기 동기화|
|`tokio::time::{sleep, timeout, interval}`|시간|
|`tokio::fs`, `tokio::process`|비동기 파일·프로세스|
|`tokio::net::{TcpListener, TcpStream, UdpSocket}`|네트워크|
|`tokio::signal::ctrl_c`|우아한 종료|
