> 📖 새벽 3시 장애. 로그에는 `println!("here")` 만 가득하다. 어느 요청에서, 어느 사용자에게, 몇 ms 만에 실패했는지 알 수 없었다.

```bash
cargo add tracing
cargo add tracing-subscriber --features env-filter,json
```

## 🧩 문제 — 로그 레벨을 조절하고, 요청별 맥락(사용자 ID 등)을 자동으로 남기고 싶다

## 💡 해결 — 이벤트(event) + 스팬(span) + `#[instrument]`

```rust
use tracing::{debug, error, info, info_span, instrument, warn};
use tracing_subscriber::EnvFilter;

#[instrument(skip(password), fields(attempt))]  // 함수 인자를 스팬 필드로 자동 기록 (비밀번호는 제외)
fn login(user_id: u64, password: &str) -> Result<(), String> {
    tracing::Span::current().record("attempt", 1);
    debug!(len = password.len(), "비밀번호 검증 시작");
    if password.len() < 8 {
        warn!("짧은 비밀번호");
        return Err("인증 실패".into());
    }
    info!("로그인 성공");
    Ok(())
}

fn main() {
    // RUST_LOG=debug cargo run  /  RUST_LOG=myapp=info,sqlx=warn
    tracing_subscriber::fmt()
        .with_env_filter(EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new("info")))
        .with_target(false)
        // .json()   // 운영에서는 JSON 포맷으로 로그 수집 시스템에 전송
        .init();

    let span = info_span!("request", request_id = %"req-42", path = "/login");
    let _guard = span.enter();                  // 이 스코프의 모든 로그에 request_id가 붙음

    if let Err(e) = login(7, "1234") {
        error!(error = %e, user_id = 7, "로그인 처리 실패");
    }
}
```

```
2026-11-08T09:12:01Z  WARN request{request_id=req-42 path="/login"}:login{user_id=7 attempt=1}: 짧은 비밀번호
2026-11-08T09:12:01Z ERROR request{request_id=req-42 path="/login"}: 로그인 처리 실패 error=인증 실패 user_id=7
```

<aside>  
⚠️

async 함수에서는 `span.enter()` 가드를 `.await` 너머로 들고 가면 안 됩니다. `#[instrument]` 를 붙이거나 `future.instrument(span)` (`tracing::Instrument` 트레이트)을 쓰세요. Axum에서는 `tower_http::trace::TraceLayer` 가 요청마다 스팬을 만들어 줍니다.

</aside>
