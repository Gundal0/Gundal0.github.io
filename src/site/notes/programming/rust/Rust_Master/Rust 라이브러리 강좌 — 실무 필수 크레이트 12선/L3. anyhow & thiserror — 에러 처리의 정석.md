## 🧩 문제 1 — 라이브러리 에러 타입을 간결하게 만들고 싶다

## 💡 해결 1 — thiserror

```rust
use thiserror::Error;

#[derive(Debug, Error)]
pub enum ConfigError {
    #[error("설정 파일을 읽을 수 없습니다")]
    Io(#[from] std::io::Error),                    // From 자동 구현 + source 연결
    #[error("포트 형식 오류: {0}")]
    Parse(#[from] std::num::ParseIntError),
    #[error("{port}번 포트는 허용되지 않습니다 (허용 범위: {min}~65535)")]
    OutOfRange { port: u16, min: u16 },
}

pub fn read_port(path: &str) -> Result<u16, ConfigError> {
    let port: u16 = std::fs::read_to_string(path)?.trim().parse()?;
    if port < 1024 { return Err(ConfigError::OutOfRange { port, min: 1024 }); }
    Ok(port)
}
```

## 🧩 문제 2 — 에러 메시지가 "No such file or directory" 뿐이라 어느 파일인지 모른다

## 💡 해결 2 — anyhow + `.context()`

```rust
use anyhow::{bail, ensure, Context, Result};

fn load_users(path: &str) -> Result<Vec<String>> {
    let text = std::fs::read_to_string(path)
        .with_context(|| format!("사용자 파일 '{path}' 을 열 수 없음"))?;
    let users: Vec<String> = text.lines().map(str::to_string).collect();
    ensure!(!users.is_empty(), "사용자 목록이 비어 있음");   // 조건 불만족 시 에러 반환
    if users.len() > 10_000 { bail!("사용자가 너무 많음: {}", users.len()); }
    Ok(users)
}

fn main() -> Result<()> {
    let port = read_port("port.txt").context("서버 설정 로드 실패")?;   // thiserror 에러도 그대로 담김
    let users = load_users("users.txt")?;
    println!("{port} {}", users.len());
    Ok(())
}
// read_port 는 위 해결 1의 함수입니다. ConfigError(thiserror)를 반환해도 anyhow가 그대로 담습니다.
```
