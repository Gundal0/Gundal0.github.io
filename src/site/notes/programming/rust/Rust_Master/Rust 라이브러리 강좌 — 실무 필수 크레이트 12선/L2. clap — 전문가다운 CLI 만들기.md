> 📖 배포 도구에 `deploy`, `rollback`, `status` 명령을 넣어야 한다. `std::env::args()` 로 직접 파싱하다 보니 `--help` 도, 오타 제안도 없다.

```bash
cargo add clap --features derive,env
```

## 🧩 문제 — 하위 명령, 옵션, 환경 변수, 도움말을 모두 지원하고 싶다

## 💡 해결 — derive API

```rust
use clap::{Parser, Subcommand, ValueEnum};

/// Crab Labs 배포 도구
#[derive(Parser, Debug)]
#[command(name = "crabctl", version, about, long_about = None)]
struct Cli {
    /// 상세 로그 (-v, -vv, -vvv)
    #[arg(short, long, action = clap::ArgAction::Count, global = true)]
    verbose: u8,

    /// API 토큰 (환경 변수 CRAB_TOKEN으로도 설정 가능)
    #[arg(long, env = "CRAB_TOKEN", hide_env_values = true)]
    token: Option<String>,

    #[command(subcommand)]
    command: Command,
}

#[derive(Subcommand, Debug)]
enum Command {
    /// 서비스를 배포한다
    Deploy {
        /// 서비스 이름
        service: String,
        #[arg(short, long, value_enum, default_value_t = Env::Staging)]
        env: Env,
        /// 실제 배포 없이 계획만 출력
        #[arg(long)]
        dry_run: bool,
    },
    /// 직전 버전으로 되돌린다
    Rollback { service: String, #[arg(long, default_value_t = 1)] steps: u32 },
    /// 상태를 본다
    Status,
}

#[derive(ValueEnum, Clone, Copy, Debug)]
enum Env { Dev, Staging, Prod }

fn main() {
    let cli = Cli::parse();
    if cli.verbose > 0 { eprintln!("verbose level {}", cli.verbose); }

    match cli.command {
        Command::Deploy { service, env, dry_run } => {
            println!("{}배포: {service} → {env:?}", if dry_run { "[DRY RUN] " } else { "" });
        }
        Command::Rollback { service, steps } => println!("↩️ {service} {steps}단계 롤백"),
        Command::Status => println!("모든 서비스 정상 ✅"),
    }
}
```

```
$ crabctl deploy api --env prod --dry-run
[DRY RUN] 배포: api → Prod

$ crabctl deplyo api
error: unrecognized subcommand 'deplyo'
  tip: a similar subcommand exists: 'deploy'
```

<aside>  
💡

`///` 문서 주석이 그대로 `--help` 문구가 됩니다. 셸 자동 완성은 `clap_complete` 크레이트로 bash/zsh/PowerShell용 스크립트를 생성할 수 있습니다.

</aside>
