> 📖 글로벌 서비스의 주문 시간이 서울과 뉴욕에서 하루씩 어긋난다. 구독 만료일 계산도 틀렸다.

```bash
cargo add chrono --features serde
cargo add chrono-tz       # 지역 시간대(Asia/Seoul 등)
```

## 🧩 문제 — 파싱, 계산, 포맷, 시간대 변환을 정확하게

## 💡 해결 — 저장은 UTC, 표시는 지역 시간

```rust
use chrono::{Datelike, Duration, Local, NaiveDate, TimeZone, Utc, Weekday};
use chrono_tz::{America::New_York, Asia::Seoul};

fn main() {
    // 현재 시각
    let now_utc = Utc::now();
    let now_local = Local::now();
    println!("UTC {now_utc} / 로컬 {}", now_local.format("%Y-%m-%d %H:%M"));

    // 시간대 변환: 같은 순간, 다른 표기
    let order = Utc.with_ymd_and_hms(2026, 11, 8, 1, 30, 0).unwrap();
    println!("서울 {} / 뉴욕 {}", order.with_timezone(&Seoul), order.with_timezone(&New_York));

    // 파싱과 날짜 계산
    let start = NaiveDate::parse_from_str("2026-01-31", "%Y-%m-%d").unwrap();
    let trial_end = start + Duration::days(14);
    let next_month = start.checked_add_months(chrono::Months::new(1)).unwrap(); // 2026-02-28 (말일 보정)
    println!("체험 종료 {trial_end}, 다음 결제일 {next_month}");

    // 요일·기간
    let days_left = (NaiveDate::from_ymd_opt(2026, 12, 25).unwrap() - Local::now().date_naive()).num_days();
    let is_weekend = matches!(start.weekday(), Weekday::Sat | Weekday::Sun);
    println!("크리스마스까지 {days_left}일, 시작일 주말? {is_weekend}");

    // RFC 3339 (API에서 가장 많이 쓰는 형식)
    let ts = chrono::DateTime::parse_from_rfc3339("2026-11-08T10:00:00+09:00").unwrap();
    println!("{}", ts.to_utc().to_rfc3339());
}
```

<aside>  
💡

**규칙**: DB·API에는 `DateTime<Utc>` 로 저장하고, 사용자에게 보여줄 때만 지역 시간대로 변환하세요. 단순히 경과 시간만 재려면 표준 라이브러리의 `std::time::Instant` 가 더 적합합니다. 더 엄격한 대안으로 `jiff` 크레이트도 있습니다.

</aside>
