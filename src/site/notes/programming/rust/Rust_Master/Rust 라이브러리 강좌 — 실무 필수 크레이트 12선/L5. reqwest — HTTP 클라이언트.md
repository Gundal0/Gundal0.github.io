> 📖 환율 API를 조회해 슬랙으로 알리는 봇을 만들어야 한다. 타임아웃, 재시도, JSON 파싱까지 제대로.

```bash
cargo add reqwest --features json
cargo add tokio --features full
cargo add serde --features derive
cargo add anyhow
```

## 🧩 문제 — API를 호출하고, 실패를 제대로 처리하고, 결과를 다른 곳으로 POST하고 싶다

## 💡 해결 — 재사용 `Client` + 타입 있는 응답

```rust
use anyhow::{Context, Result};
use serde::{Deserialize, Serialize};
use std::time::Duration;

#[derive(Debug, Deserialize)]
struct Repo { full_name: String, stargazers_count: u64 }

#[derive(Serialize)]
struct SlackMsg<'a> { text: &'a str }

async fn get_with_retry(client: &reqwest::Client, url: &str, tries: u32) -> Result<reqwest::Response> {
    let mut last_err = None;
    for attempt in 1..=tries {
        match client.get(url).send().await.and_then(|r| r.error_for_status()) {
            Ok(resp) => return Ok(resp),
            Err(e) => {
                eprintln!("시도 {attempt} 실패: {e}");
                last_err = Some(e);
                tokio::time::sleep(Duration::from_millis(200 * 2u64.pow(attempt))).await; // 지수 백오프
            }
        }
    }
    Err(last_err.unwrap()).context(format!("{url} 호출 최종 실패"))
}

#[tokio::main]
async fn main() -> Result<()> {
    // Client는 내부에 커넥션 풀이 있으므로 한 번 만들어 재사용
    let client = reqwest::Client::builder()
        .timeout(Duration::from_secs(10))
        .user_agent("crab-bot/0.1")
        .build()?;

    let repo: Repo = get_with_retry(&client, "<https://api.github.com/repos/rust-lang/rust>", 3)
        .await?
        .json()
        .await?;
    let text = format!("⭐ {} : {}개", repo.full_name, repo.stargazers_count);
    println!("{text}");

    if let Ok(webhook) = std::env::var("SLACK_WEBHOOK") {
        client.post(webhook).json(&SlackMsg { text: &text }).send().await?.error_for_status()?;
    }
    Ok(())
}
```

<aside>  
💡

비동기 런타임 없이 간단히 쓰려면 `reqwest` 의 `blocking` 기능을 켜고 `reqwest::blocking::get(url)?.text()?` 처럼 쓸 수 있습니다. 크로스 컴파일이 중요하면 OpenSSL 대신 `rustls-tls` 기능을 고려하세요.

</aside>
