> 📖 외부 API가 돌려주는 JSON을 하린은 문자열 자르기로 파싱하고 있었다. 필드 순서가 바뀌자 전부 깨졌다.

```bash
cargo add serde --features derive
cargo add serde_json
```

## 🧩 문제 1 — JSON을 타입 안전하게 읽고 쓰고 싶다

## 💡 해결 1 — `#[derive(Serialize, Deserialize)]`

```rust
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]          // Rust: user_name  ↔  JSON: userName
struct User {
    id: u64,
    user_name: String,
    #[serde(default)]                       // JSON에 없으면 Default (false)
    is_admin: bool,
    #[serde(skip_serializing_if = "Option::is_none")]
    nickname: Option<String>,               // null/누락 → None
    #[serde(rename = "created")]
    created_at: String,
    tags: Vec<String>,
}

fn main() -> Result<(), serde_json::Error> {
    let raw = r#"{ "id": 7, "userName": "하린", "created": "2026-11-08", "tags": ["rust"] }"#;
    let user: User = serde_json::from_str(raw)?;           // JSON → 구조체
    println!("{user:#?}");
    println!("{}", serde_json::to_string_pretty(&user)?);  // 구조체 → JSON
    Ok(())
}
```

## 🧩 문제 2 — 구조가 일정하지 않은 JSON

## 💡 해결 2 — `serde_json::Value` 와 `json!`

```rust
use serde_json::{json, Value};

fn main() {
    let v: Value = serde_json::from_str(r#"{"data":{"items":[{"price":1200},{"price":800}]}}"#).unwrap();
    let total: i64 = v["data"]["items"]
        .as_array()
        .map(|items| items.iter().filter_map(|i| i["price"].as_i64()).sum())
        .unwrap_or(0);
    println!("{total}"); // 2000

    let body = json!({ "event": "signup", "user": { "id": 7 }, "tags": ["web", "ko"] });
    println!("{body}");
}
```

## 🧩 문제 3 — 열거형을 JSON으로 표현하고 싶다

## 💡 해결 3 — 태그 방식 선택

```rust
#[derive(Debug, serde::Serialize, serde::Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]   // 내부 태그 방식
enum Event {
    Click { x: i32, y: i32 },
    KeyPress { key: String },
}
// Event::Click{x:1,y:2}  →  {"type":"click","x":1,"y":2}
```

<aside>  
💡

serde는 **형식과 무관**합니다. 같은 derive로 `toml`, `serde_yaml`, `csv`, `bincode`, `rmp-serde`(MessagePack)까지 지원합니다. 예: `let cfg: Config = toml::from_str(&text)?;`

</aside>
