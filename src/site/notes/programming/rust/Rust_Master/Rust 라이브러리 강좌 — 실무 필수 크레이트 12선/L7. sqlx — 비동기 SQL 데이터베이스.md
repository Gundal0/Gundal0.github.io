## 🧩 문제 — 데이터를 저장·조회하고, 여러 작업을 한 번에 커밋해야 한다

## 💡 해결 — 커넥션 풀 + 바인딩 + FromRow + 트랜잭션

```rust
use anyhow::Result;
use sqlx::sqlite::SqlitePool;

#[derive(Debug, sqlx::FromRow)]
struct Inquiry {
    id: i64,
    name: String,
    email: String,
    message: String,
}

#[tokio::main]
async fn main() -> Result<()> {
    // mode=rwc: 파일이 없으면 생성
    let pool = SqlitePool::connect("sqlite:crab.db?mode=rwc").await?;

    sqlx::query(
        "CREATE TABLE IF NOT EXISTS inquiries (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            name TEXT NOT NULL, email TEXT NOT NULL, message TEXT NOT NULL)",
    )
    .execute(&pool)
    .await?;

    // ✅ 바인딩(?)을 쓰면 SQL 인젝션이 불가능. 절대 format!으로 SQL을 만들지 마세요.
    let id = sqlx::query("INSERT INTO inquiries (name, email, message) VALUES (?, ?, ?)")
        .bind("하린")
        .bind("harin@crab.dev")
        .bind("견적 문의드립니다")
        .execute(&pool)
        .await?
        .last_insert_rowid();
    println!("새 문의 id = {id}");

    // 트랜잭션: 모두 성공하거나 모두 취소 (중간에 ? 로 빠져나가면 자동 롤백)
    let mut tx = pool.begin().await?;
    for name in ["페리스", "지우"] {
        sqlx::query("INSERT INTO inquiries (name, email, message) VALUES (?, ?, ?)")
            .bind(name).bind("x@crab.dev").bind("대량 등록")
            .execute(&mut *tx)
            .await?;
    }
    tx.commit().await?;

    // 조회 → 구조체
    let rows: Vec<Inquiry> = sqlx::query_as("SELECT id, name, email, message FROM inquiries ORDER BY id DESC LIMIT ?")
        .bind(10)
        .fetch_all(&pool)
        .await?;
    for r in &rows { println!("#{} {} <{}>: {}", r.id, r.name, r.email, r.message); }

    let count: (i64,) = sqlx::query_as("SELECT COUNT(*) FROM inquiries").fetch_one(&pool).await?;
    println!("총 {}건", count.0);
    Ok(())
}
```

## 🔍 한 단계 더 — 컴파일 타임 검사 매크로와 마이그레이션

```bash
cargo install sqlx-cli
export DATABASE_URL=sqlite:crab.db
sqlx migrate add create_inquiries     # migrations/xxxx_create_inquiries.sql 생성
sqlx migrate run
```

```rust
// DATABASE_URL이 있으면 컴파일 시 실제 DB에 물어 컬럼 이름·타입을 검사합니다
let row = sqlx::query!("SELECT name, email FROM inquiries WHERE id = ?", id)
    .fetch_one(&pool)
    .await?;
println!("{} {}", row.name, row.email);   // 오타가 나면 컴파일 오류!

sqlx::migrate!().run(&pool).await?;       // 앱 시작 시 마이그레이션 자동 적용
```
