> 📖 고객센터 로그에서 주문번호(`ORD-2026-000123`)와 이메일을 뽑고, 전화번호는 마스킹해야 한다.

```bash
cargo add regex
```

## 🧩 문제 — 패턴 추출, 치환, 검증을 빠르고 안전하게

## 💡 해결 — 한 번 컴파일해서 재사용하는 `Regex`

```rust
use regex::Regex;
use std::sync::LazyLock;

// 정규식 컴파일은 비싸므로 전역에 한 번만 (루프 안에서 Regex::new 금지)
static ORDER: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"ORD-(?<year>\d{4})-(?<seq>\d{6})").unwrap());
static EMAIL: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"[\w.+-]+@[\w-]+\.[\w.]+").unwrap());
static PHONE: LazyLock<Regex> = LazyLock::new(|| Regex::new(r"(01[016789])-?(\d{3,4})-?(\d{4})").unwrap());

fn main() {
    let log = "고객(harin@crab.dev, 010-1234-5678)이 ORD-2026-000123, ORD-2025-000999 환불 요청";

    // 이름 있는 그룹 캡처
    for caps in ORDER.captures_iter(log) {
        println!("연도 {} / 번호 {}", &caps["year"], &caps["seq"]);
    }

    // 첫 매치
    if let Some(m) = EMAIL.find(log) {
        println!("이메일: {} (위치 {}..{})", m.as_str(), m.start(), m.end());
    }

    // 치환: $1 같은 참조
    let masked = PHONE.replace_all(log, "$1-****-$3");
    println!("{masked}");

    // 검증 (전체 일치는 ^...$)
    let valid = Regex::new(r"^[a-z0-9_]{4,16}$").unwrap();
    println!("{} {}", valid.is_match("harin_01"), valid.is_match("하린"));
}
```

<aside>  
🔍

Rust의 `regex` 는 **선형 시간**을 보장해 악의적인 입력으로 서비스가 멈추는 ReDoS 공격에 강합니다. 대신 역참조(`\1`)와 전방탐색(lookaround)은 지원하지 않습니다(필요하면 `fancy-regex`).

</aside>
