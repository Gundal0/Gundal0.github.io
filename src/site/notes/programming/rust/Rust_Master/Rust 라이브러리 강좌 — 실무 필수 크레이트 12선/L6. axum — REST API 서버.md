> 📖 P3에서 HTML 페이지를 만들었다면, 이번에는 P4 모바일 앱이 호출할 **JSON REST API**가 필요하다.

```bash
cargo add axum
cargo add tokio --features full
cargo add serde --features derive
```

## 🧩 문제 — 서버 전역 상태를 공유하면서 CRUD API를 만들고 싶다

## 💡 해결 — `State` + `Json` + `Path` + `Query` 추출기

```rust
use axum::{
    extract::{Path, Query, State},
    http::StatusCode,
    routing::get,
    Json, Router,
};
use serde::{Deserialize, Serialize};
use std::sync::{Arc, RwLock};

#[derive(Clone, Serialize)]
struct Todo { id: u64, title: String, done: bool }

#[derive(Deserialize)]
struct NewTodo { title: String }

#[derive(Deserialize)]
struct ListQuery { done: Option<bool> }

#[derive(Clone, Default)]
struct AppState { todos: Arc<RwLock<Vec<Todo>>> }   // 핸들러들이 공유하는 상태 (17장 복습)

async fn list(State(s): State<AppState>, Query(q): Query<ListQuery>) -> Json<Vec<Todo>> {
    let todos = s.todos.read().unwrap();
    Json(todos.iter().filter(|t| q.done.is_none_or(|d| t.done == d)).cloned().collect())
}

async fn create(State(s): State<AppState>, Json(input): Json<NewTodo>) -> Result<(StatusCode, Json<Todo>), (StatusCode, String)> {
    if input.title.trim().is_empty() {
        return Err((StatusCode::UNPROCESSABLE_ENTITY, "title이 비었습니다".into()));
    }
    let mut todos = s.todos.write().unwrap();
    let todo = Todo { id: todos.len() as u64 + 1, title: input.title, done: false };
    todos.push(todo.clone());
    Ok((StatusCode::CREATED, Json(todo)))
}

async fn toggle(State(s): State<AppState>, Path(id): Path<u64>) -> Result<Json<Todo>, StatusCode> {
    let mut todos = s.todos.write().unwrap();
    let todo = todos.iter_mut().find(|t| t.id == id).ok_or(StatusCode::NOT_FOUND)?;
    todo.done = !todo.done;
    Ok(Json(todo.clone()))
}

#[tokio::main]
async fn main() {
    let app = Router::new()
        .route("/api/todos", get(list).post(create))
        .route("/api/todos/{id}/toggle", axum::routing::post(toggle))
        .with_state(AppState::default());

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    axum::serve(listener, app).await.unwrap();
}
```

```bash
curl -X POST localhost:3000/api/todos -H 'content-type: application/json' -d '{"title":"Rust 공부"}'
curl -X POST localhost:3000/api/todos/1/toggle
curl 'localhost:3000/api/todos?done=true'
```

<aside>  
🔍

**추출기(Extractor)**는 핸들러 인자의 타입만으로 요청에서 무엇을 꺼낼지 결정합니다. JSON 본문이 잘못되면 핸들러가 호출되기 전에 400/422가 자동 반환됩니다. **본문을 소비하는 추출기(`Json`, `Form`)는 마지막 인자**여야 합니다.

</aside>
