> 📖 **스토리** — 하린은 센서 온도를 평균 내는 함수를 맡았다. 테스트 데이터를 넣자 프로그램이 `attempt to add with overflow` 라며 멈춰 버렸다.

## 🧩 문제 1 — 정수 오버플로

```rust
fn main() {
    let a: u8 = 200;
    let b: u8 = 100;
    let sum = a + b; // 디버그 빌드: panic! (u8의 최대값은 255)
    println!("{sum}");
}
```

## 💡 해결 1 — 알맞은 타입과 명시적 오버플로 처리

```rust
fn main() {
    let a: u8 = 200;
    let b: u8 = 100;

    println!("{:?}", a.checked_add(b));    // None        — 넘치면 None
    println!("{}", a.wrapping_add(b));      // 44          — 한 바퀴 돌기
    println!("{}", a.saturating_add(b));    // 255         — 최대값에서 멈춤
    println!("{:?}", a.overflowing_add(b)); // (44, true)  — 결과 + 넘침 여부

    let sum = a as u32 + b as u32;          // 더 큰 타입으로 변환 후 계산
    println!("{sum}");                      // 300
}
```

<aside>  
🔍

디버그 빌드에서는 오버플로 시 panic, 릴리스 빌드에서는 기본적으로 wrapping됩니다. 의도를 코드에 드러내려면 `checked_*` 등을 쓰세요.

</aside>

## 🔍 원리 — Rust의 타입 지도

### 스칼라 타입

|분류|타입|예|
|---|---|---|
|부호 있는 정수|`i8` `i16` `i32`(기본) `i64` `i128` `isize`|`-5`, `1_000_000i64`|
|부호 없는 정수|`u8` `u16` `u32` `u64` `u128` `usize`(인덱스용)|`0xff`, `0o77`, `0b1010`, `b'A'`|

|문자|`char` (4바이트 유니코드 스칼라)|`'가'`, `'🦀'`|

### 복합 타입

```rust
fn main() {
    // 튜플: 서로 다른 타입을 묶음
    let reading: (&str, f64, bool) = ("서울", 21.5, true);
    let (city, temp, ok) = reading;          // 구조 분해
    println!("{city} {temp} {ok} / {}", reading.1);

    // 배열: 같은 타입, 고정 길이, 스택에 저장
    let temps: [f64; 5] = [20.1, 21.5, 19.8, 22.0, 20.6];
    let zeros = [0u8; 3];                    // [0, 0, 0]
    println!("첫 온도 {}, 길이 {}, {:?}", temps[0], temps.len(), zeros);

    // 유닛 타입: 값이 없음을 나타내는 ()
    let nothing: () = ();
    println!("{nothing:?}");
}
```

## 🧩 문제 2 — 평균 함수가 값을 돌려주지 않는다

```rust
fn average(values: &[f64]) -> f64 {
    let sum: f64 = values.iter().sum();
    sum / values.len() as f64;   // ❌ 세미콜론 때문에 ()가 반환됨 → E0308
}
```

## 💡 해결 2 — 문(statement)과 식(expression)을 구분한다

Rust에서 블록의 **마지막 식**은 그 블록의 값입니다. 세미콜론을 붙이면 식이 문이 되어 값이 사라집니다.

```rust
/// 온도 배열의 평균을 반환한다. 빈 배열이면 0.0
fn average(values: &[f64]) -> f64 {
    if values.is_empty() {
        return 0.0;                  // 조기 반환은 return
    }
    let sum: f64 = values.iter().sum();
    sum / values.len() as f64        // ✅ 세미콜론 없음 = 반환값
}

fn main() {
    let temps = [20.1, 21.5, 19.8];
    println!("평균: {:.2}", average(&temps)); // 평균: 20.47

    // 블록도 식이다
    let grade = {
        let avg = average(&temps);
        if avg > 20.0 { "따뜻함" } else { "선선함" }
    };
    println!("{grade}");
}
```

<aside>  
💡

**함수 문법 요약**: `fn 이름(매개변수: 타입, ...) -> 반환타입 { ... }`. 매개변수 타입은 **반드시** 적어야 하고, 반환값이 없으면 `-> ()` 를 생략합니다. 절대 반환하지 않는 함수는 `-> !`(never 타입)입니다.

</aside>

### 포맷 문자열 치트시트

|코드|출력|
|---|---|
|`println!("{x}")`|변수 직접 캡처|
|`println!("{:?}", v)` / `{:#?}`|Debug 출력 / 예쁘게|
|`println!("{:.2}", 3.14159)`|`3.14`|
|`println!("{:>8}", "hi")`|오른쪽 정렬 8칸|
|`println!("{:08.3}", 3.14)`|`0003.140`|
|`println!("{:#x} {:b}", 255, 5)`|`0xff 101`|
|`eprintln!(...)`|표준 에러로 출력|
|`format!(...)`|String으로 반환|
