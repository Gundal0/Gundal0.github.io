> 📖 **스토리** — 입사 첫날, 페리스가 노트북을 건네며 말했다. "우리 팀은 Windows, macOS, Ubuntu를 모두 써. 어느 OS에서든 같은 방식으로 Rust를 개발할 수 있어야 해. 오늘 목표는 딱 하나, Hello World를 띄우는 거야."

## 🧩 문제 1 — Rust는 어떻게 설치하지?

하린은 검색해 보니 설치 방법이 제각각이라 혼란스러웠다. 패키지 관리자로 설치해야 할까, 공식 사이트에서 받아야 할까?

## 💡 해결 1 — rustup으로 설치한다

**rustup**은 Rust 툴체인(컴파일러 `rustc`, 빌드 도구 `cargo`, 표준 라이브러리)을 설치·업데이트하는 공식 관리자입니다. OS와 상관없이 rustup을 쓰는 것이 정답입니다.

Windows

1. [rustup.rs](https://rustup.rs)에서 `rustup-init.exe` 를 내려받아 실행합니다.
2. 안내에 따라 **Visual Studio C++ Build Tools**(MSVC 링커)를 함께 설치합니다. 이것이 없으면 `link.exe not found` 오류가 납니다.
3. 새 터미널(PowerShell)을 열고 확인합니다.

```bash
rustc --version
cargo --version
```

macOS

```bash
# C 링커 등 기본 개발 도구
xcode-select --install

# rustup 설치
curl --proto '=https' --tlsv1.2 -sSf <https://sh.rustup.rs> | sh

# 현재 쉘에 경로 반영
source "$HOME/.cargo/env"
rustc --version
```

Ubuntu

```bash
sudo apt update
sudo apt install -y build-essential curl pkg-config libssl-dev

curl --proto '=https' --tlsv1.2 -sSf <https://sh.rustup.rs> | sh
source "$HOME/.cargo/env"
rustc --version
```

<aside>  
💡

자주 쓰는 rustup 명령어: `rustup update`(최신 버전으로 업데이트), `rustup doc --book`(오프라인 공식 교재 열기), `rustup component add clippy rustfmt`(린터·포맷터 설치)

</aside>

## 🧩 문제 2 — 메모장으로 코딩하기엔 너무 힘들다

자동 완성도, 오류 표시도 없으면 Rust의 엄격한 컴파일러와 싸우기 어렵습니다.

## 💡 해결 2 — Antigravity IDE 설정

**Antigravity**는 Google이 만든 **에이전트 중심 IDE**입니다. VS Code 계열 편집기를 기반으로 하므로 확장 프로그램과 단축키가 익숙하고, 내장 AI 에이전트에게 작업을 맡기고 결과(계획·변경사항·스크린샷 등)를 검토할 수 있습니다.

1. [antigravity.google](https://antigravity.google)에서 OS에 맞는 설치 파일을 내려받아 설치합니다.
2. 처음 실행 시 Google 계정으로 로그인하고, 에이전트의 자율 수준(명령 실행 전 승인 여부 등)을 선택합니다. 처음에는 **검토 후 실행** 모드를 권장합니다.
3. **Extensions** 패널에서 다음 확장을 설치합니다.

|확장|역할|
|---|---|
|**rust-analyzer** (필수)|자동 완성, 타입 힌트, 오류 표시, 리팩터링, ▶ Run/Debug 버튼|
|**CodeLLDB**|중단점(breakpoint) 디버깅|
|**Even Better TOML**|`Cargo.toml` 문법 강조|
|**Error Lens**|오류 메시지를 코드 줄 옆에 바로 표시|

1. 설정(`settings.json`)에 저장 시 자동 포맷과 Clippy 검사를 켭니다.

```json
{
  "editor.formatOnSave": true,
  "rust-analyzer.check.command": "clippy",
  "rust-analyzer.inlayHints.typeHints.enable": true
}
```

## 🧩 문제 3 — 프로젝트는 어떻게 만들고 실행하지?

## 💡 해결 3 — Cargo

Antigravity의 터미널(`Ctrl+``)을 열고 입력합니다.

```bash
cargo new hello_crab
cd hello_crab
antigravity .   # 또는 File → Open Folder
```

```
hello_crab/
├── Cargo.toml      # 프로젝트 설정과 의존성 목록
└── src/
    └── main.rs     # 프로그램 시작점
```

```rust
// src/main.rs
fn main() {
    println!("Hello, Crab Labs! 🦀");
}
```

```bash
cargo run          # 빌드 + 실행
cargo check        # 빠른 컴파일 검사(실행 파일 생성 없음)
cargo build --release   # 최적화된 배포용 빌드 → target/release/
cargo fmt          # 코드 포맷
cargo clippy       # 린트(더 좋은 코드 제안)
cargo test         # 테스트 실행
cargo doc --open   # 문서 생성 후 브라우저로 열기
```

<aside>  
🤖

**Antigravity 팁**

- `fn main()` 위에 나타나는 **▶ Run | Debug** 코드 렌즈를 클릭하면 바로 실행·디버깅됩니다.
- 에이전트에게 "이 컴파일 오류가 왜 났는지 초보자에게 설명해줘. 코드는 고치지 마"처럼 **설명만** 요청하면 학습 효과가 가장 큽니다.
- 에이전트가 제안한 명령이나 변경사항은 항상 내용을 읽고 승인하세요.  
    </aside>

## 🔍 원리 — Cargo.toml

```toml
[package]
name = "hello_crab"
version = "0.1.0"
edition = "2024"     # 언어 에디션

[dependencies]
# 외부 라이브러리(크레이트)를 여기에 추가. 예: rand = "0.9"
# 터미널에서 `cargo add rand` 로 추가할 수도 있다.
```

<aside>  
⚠️

**함정** — Rust 컴파일러의 오류 메시지는 길지만 매우 친절합니다. **끝까지 읽으세요.** `help:` 줄에 해결책이 적혀 있는 경우가 많습니다. `rustc --explain E0382` 처럼 오류 코드로 자세한 설명도 볼 수 있습니다.

</aside>
