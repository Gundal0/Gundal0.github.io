## 14.1 Claude Code 설치와 시작

```bash
# macOS / Linux 네이티브 설치
curl -fsSL <https://claude.ai/install.sh> | bash

# 또는 npm
npm install -g @anthropic-ai/claude-code

# 프로젝트 폴더에서 실행
cd my-project
claude
```

터미널 외에도 VS Code·JetBrains 확장, Claude 데스크톱 앱의 Code 탭, 웹([claude.ai/code)에서](http://claude.ai/code)에서) 사용할 수 있습니다.

## 14.3 기능 한눈에 보기

|기능|설명|사용법|
|---|---|---|
|[**CLAUDE.md**](http://CLAUDE.md)|프로젝트 규칙·빌드 명령·컨벤션을 적어두면 매 세션 자동 로드|`/init` 으로 초안 생성|
|**Plan Mode**|코드를 수정하지 않고 계획만 수립|`Shift+Tab` 으로 전환|
|**슬래시 명령 / Skills**|자주 쓰는 작업을 명령어로|`.claude/skills/<이름>/SKILL.md`|
|**서브에이전트**|독립된 컨텍스트를 가진 전문 에이전트(리뷰어, 테스터 등)|`.claude/agents/<이름>.md`|
|**Hooks**|도구 실행 전후에 쉘 명령을 자동 실행 (포맷터, 검사)|`.claude/settings.json`|
|**MCP**|외부 도구 연결 (13장)|`claude mcp add`|
|**Headless 모드**|비대화형 실행 — CI/CD, 스크립트에 통합|`claude -p "..."`|

### [CLAUDE.md](http://CLAUDE.md) 예시

```markdown
# 프로젝트: 주문 관리 서비스

## 명령어
- 테스트: `pytest -q`
- 린트: `ruff check . && ruff format --check .`
- 로컬 실행: `uvicorn app.main:app --reload`

## 규칙
- 새 API는 반드시 `tests/api/` 에 테스트를 추가한다.
- DB 스키마 변경은 Alembic 마이그레이션으로만 한다.
- `app/legacy/` 는 수정하지 않는다 (폐기 예정).
```

### Hook 예시 — 파일 수정 후 자동 포맷

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "ruff format ." }]
      }
    ]
  }
}
```

### 서브에이전트 예시 — 보안 리뷰어

```markdown
---
name: security-reviewer
description: 코드 변경사항의 보안 취약점을 검토한다. 인증, 입력 검증, 비밀 정보 처리 코드가 바뀌면 사용한다.
tools: Read, Grep, Glob
---

너는 시니어 보안 엔지니어야. 변경된 코드에서 다음을 찾아라.
- SQL/명령어 인젝션, XSS, 경로 조작
- 하드코딩된 비밀 정보
- 인증·인가 누락
각 발견 사항은 파일:라인, 위험도, 수정 제안으로 보고한다.
```

## 14.4 Claude Agent SDK — Claude Code를 라이브러리로

Agent SDK는 Claude Code의 에이전트 루프, 내장 도구(Read·Write·Edit·Bash·Grep·WebSearch 등), 컨텍스트 관리, 권한 제어를 그대로 제공합니다. 11장의 Tool Runner는 내가 정의한 도구만 반복하지만, Agent SDK는 파일·쉘까지 다루는 범용 에이전트를 바로 만들 수 있습니다.

Python

```bash
pip install claude-agent-sdk
```

```python
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions

async def main():
    options = ClaudeAgentOptions(
        system_prompt="너는 코드 품질 감사관이야. 발견 사항을 표로 정리해.",
        allowed_tools=["Read", "Grep", "Glob"],   # 읽기 전용 권한만 부여
        cwd="./my-project",
        max_turns=20,
    )
    async for message in query(prompt="TODO 주석과 사용되지 않는 함수를 찾아줘", options=options):
        print(message)

asyncio.run(main())
```

TypeScript

```bash
npm install @anthropic-ai/claude-agent-sdk
```

```tsx
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "TODO 주석과 사용되지 않는 함수를 찾아줘",
  options: {
    systemPrompt: "너는 코드 품질 감사관이야. 발견 사항을 표로 정리해.",
    allowedTools: ["Read", "Grep", "Glob"],
    cwd: "./my-project",
    maxTurns: 20,
  },
})) {
  if (message.type === "result") console.log(message);
}
```

## 14.5 에이전트를 만드는 4가지 방법 비교

|방식|내가 작성하는 것|루프|실행 인프라|추천 상황|
|---|---|---|---|---|
|① 수동 루프|루프 + 도구|직접 구현|직접 운영|완전한 제어가 필요할 때|
|② Tool Runner|도구 함수만|SDK|직접 운영|내 도구 중심의 에이전트 (대부분)|
|③ Agent SDK|프롬프트 + 옵션|Claude Code 엔진|직접 운영|파일·쉘을 다루는 범용/코딩 에이전트|
|④ Managed Agents|에이전트 설정|Anthropic|Anthropic 호스팅 샌드박스|장시간·예약 실행, 인프라 관리 부담을 줄이고 싶을 때 (베타)|
