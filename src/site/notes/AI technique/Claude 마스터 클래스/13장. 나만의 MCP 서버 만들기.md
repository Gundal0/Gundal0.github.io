## 13.1 만들 것: 사내 할 일(To-do) MCP 서버

다음 3가지를 제공하는 서버를 만듭니다.

- 🔧 **Tool** `add_todo`, `list_todos`, `complete_todo`
- 📄 **Resource** `todos://summary` — 현재 할 일 요약
- 💬 **Prompt** `daily_plan` — 오늘의 계획 세우기 템플릿

## 13.2 Python 구현 (FastMCP)

```bash
# uv 사용 권장 (pip install "mcp[cli]" 도 가능)
uv init todo-mcp && cd todo-mcp
uv add "mcp[cli]"
```

```python
# server.py
import json
from pathlib import Path
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("todo")
DB = Path(__file__).with_name("todos.json")

def _load() -> list[dict]:
    return json.loads(DB.read_text(encoding="utf-8")) if DB.exists() else []

def _save(todos: list[dict]) -> None:
    DB.write_text(json.dumps(todos, ensure_ascii=False, indent=2), encoding="utf-8")

@mcp.tool()
def add_todo(title: str, due: str | None = None) -> str:
    """할 일을 추가한다.

    Args:
        title: 할 일 내용
        due: 마감일 (YYYY-MM-DD, 선택)
    """
    todos = _load()
    todo = {"id": len(todos) + 1, "title": title, "due": due, "done": False}
    todos.append(todo)
    _save(todos)
    return f"추가됨: #{todo['id']} {title}"

@mcp.tool()
def list_todos(include_done: bool = False) -> list[dict]:
    """할 일 목록을 반환한다. include_done=True이면 완료 항목도 포함한다."""
    return [t for t in _load() if include_done or not t["done"]]

@mcp.tool()
def complete_todo(todo_id: int) -> str:
    """ID에 해당하는 할 일을 완료 처리한다."""
    todos = _load()
    for t in todos:
        if t["id"] == todo_id:
            t["done"] = True
            _save(todos)
            return f"완료: #{todo_id} {t['title']}"
    raise ValueError(f"#{todo_id} 항목을 찾을 수 없습니다.")

@mcp.resource("todos://summary")
def summary() -> str:
    """남은 할 일 개수와 가장 급한 항목 요약"""
    open_todos = [t for t in _load() if not t["done"]]
    urgent = sorted([t for t in open_todos if t["due"]], key=lambda t: t["due"])[:3]
    lines = [f"남은 할 일: {len(open_todos)}개"] + [f"- {t['due']} {t['title']}" for t in urgent]
    return "\n".join(lines)

@mcp.prompt()
def daily_plan(focus_hours: int = 6) -> str:
    """오늘의 업무 계획을 세우는 프롬프트"""
    return (
        f"list_todos 도구로 할 일을 확인하고, 마감일과 중요도를 고려해 "
        f"집중 시간 {focus_hours}시간 안에 끝낼 수 있는 오늘의 시간표를 만들어줘."
    )

if __name__ == "__main__":
    mcp.run(transport="stdio")
```

<aside>  
⚠️

**stdio 서버에서 `print()` 금지!** 표준 출력(stdout)은 MCP 프로토콜 메시지 통로입니다. 디버그 로그는 반드시 `stderr` 나 `logging` 을 사용하세요.

</aside>

## 13.3 TypeScript 구현

```bash
npm install @modelcontextprotocol/sdk zod
```

```tsx
// server.ts
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

type Todo = { id: number; title: string; done: boolean };
const todos: Todo[] = [];

const server = new McpServer({ name: "todo", version: "1.0.0" });

server.registerTool(
  "add_todo",
  {
    title: "할 일 추가",
    description: "할 일을 추가한다.",
    inputSchema: { title: z.string().describe("할 일 내용") },
  },
  async ({ title }) => {
    const todo = { id: todos.length + 1, title, done: false };
    todos.push(todo);
    return { content: [{ type: "text", text: `추가됨: #${todo.id} ${title}` }] };
  },
);

server.registerTool(
  "list_todos",
  { title: "할 일 목록", description: "미완료 할 일 목록을 반환한다.", inputSchema: {} },
  async () => ({
    content: [{ type: "text", text: JSON.stringify(todos.filter((t) => !t.done), null, 2) }],
  }),
);

const transport = new StdioServerTransport();
await server.connect(transport);
console.error("todo MCP 서버 실행 중"); // 로그는 stderr로!
```

## 13.5 Claude에 연결하기

Claude Code

```bash
# 현재 프로젝트에 로컬(stdio) 서버 등록
claude mcp add todo -- uv run --directory /abs/path/todo-mcp server.py

# 등록 확인
claude mcp list
```

Claude Code 안에서 `/mcp` 를 입력하면 연결 상태를 확인할 수 있습니다.

Claude 데스크톱

```json
{
  "mcpServers": {
    "todo": {
      "command": "uv",
      "args": ["run", "--directory", "/abs/path/todo-mcp", "server.py"]
    }
  }
}
```

Claude API (원격 서버)

서버를 Streamable HTTP로 배포했다면 Messages API의 MCP 커넥터로 바로 연결할 수 있습니다. `mcp_servers` 와 `mcp_toolset` 도구를 **둘 다** 지정해야 합니다.

```python
response = client.beta.messages.create(
    model="claude-opus-5-5",
    max_tokens=4096,
    betas=["mcp-client-2025-11-20"],
    mcp_servers=[{"type": "url", "url": "<https://todo.example.com/mcp>", "name": "todo"}],
    tools=[{"type": "mcp_toolset", "mcp_server_name": "todo"}],
    messages=[{"role": "user", "content": "오늘 마감인 할 일 알려줘"}],
)
```

## 13.6 원격 배포와 보안

### 🌐 Streamable HTTP로 바꾸기

FastMCP는 transport만 바꾸면 HTTP 서버가 됩니다. 이후 컨테이너로 클라우드에 배포하고 [claude.ai](http://claude.ai)의 _Add custom connector_에 URL을 등록합니다.

```python
if __name__ == "__main__":
    mcp.run(transport="streamable-http")   # 기본 경로: /mcp
```

### 🛡️ 보안 체크리스트

- 원격 서버는 **OAuth 인증**을 구현하고 사용자별 권한을 검사하세요.
- 도구 입력은 신뢰하지 말고 검증하세요. SQL은 파라미터 바인딩, 파일 경로는 허용 디렉터리 밖으로 못 나가게.
- 삭제·전송 같은 파괴적 도구는 이름과 설명에 명확히 표시해 호스트가 사용자 승인을 받게 하세요.
- 도구 결과에 포함된 외부 텍스트는 프롬프트 인젝션 통로가 될 수 있음을 기억하세요.
