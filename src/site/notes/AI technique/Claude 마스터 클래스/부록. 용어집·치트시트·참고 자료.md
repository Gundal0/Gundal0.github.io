## A. 용어집

|용어|뜻|
|---|---|
|**LLM**|대규모 언어 모델. 방대한 텍스트로 학습해 다음 토큰을 예측하는 신경망|
|**토큰(Token)**|모델이 처리하는 텍스트의 최소 단위. 비용·길이의 기준|
|**컨텍스트 윈도우**|모델이 한 번에 참고할 수 있는 최대 토큰 수|
|**프롬프트**|모델에 주는 입력(지시·맥락·자료)|
|**시스템 프롬프트**|대화 전체에 적용되는 역할·규칙 지시문|
|**환각(Hallucination)**|사실이 아닌 내용을 그럴듯하게 생성하는 현상|
|**Few-shot**|프롬프트에 예시를 몇 개 포함해 원하는 패턴을 보여주는 기법|
|**확장/적응형 사고**|답하기 전에 모델이 내부적으로 추론하는 기능. 적응형은 모델이 사고량을 스스로 결정|
|**Effort**|사고 깊이와 토큰 사용량을 조절하는 API 파라미터 (low ~ max)|
|**Artifact**|[claude.ai](http://claude.ai)에서 독립 패널에 표시되는 문서·코드·앱 결과물|
|**Project**|지침 + 지식 + 대화를 묶은 작업 공간|
|**RAG**|검색 증강 생성. 관련 문서를 검색해 프롬프트에 넣고 답하는 방식|
|**Skill**|[SKILL.md](http://SKILL.md)와 리소스로 구성된 재사용 가능한 업무 노하우 패키지|
|**MCP**|Model Context Protocol. AI 앱과 외부 도구·데이터를 연결하는 개방형 표준|
|**Tool Use**|모델이 개발자가 정의한 함수를 호출하도록 요청하는 기능 (Function Calling)|
|**에이전트**|목표를 받아 계획·도구 사용·검증을 스스로 반복하는 AI 시스템|
|**프롬프트 캐싱**|반복되는 프롬프트 앞부분을 저장해 비용·지연을 줄이는 기능|
|**프롬프트 인젝션**|외부 데이터에 숨긴 지시로 모델의 행동을 조작하려는 공격|

## B. 프롬프트 치트시트

### 상황별 한 줄 추가구

- 더 정확하게 → "확실하지 않으면 모른다고 말해줘"
- 더 깊게 → "반대 관점에서도 검토해줘"
- 더 짧게 → "결론부터 3줄로"
- 더 쉬운 말로 → "중학생에게 설명하듯"
- 더 실용적으로 → "내일 바로 할 수 있는 액션으로"

### 구조화 태그 모음

- `<context>` 배경 설명
- `<document>` 참고 자료
- `<instructions>` 지시 사항
- `<example>` 예시
- `<output_format>` 출력 형식

## C. API 치트시트 (Python)

```python
import anthropic
client = anthropic.Anthropic()

# 기본 호출
client.messages.create(model="claude-opus-5-5", max_tokens=1024,
                       messages=[{"role": "user", "content": "..."}])

# 시스템 프롬프트 + effort
client.messages.create(model="claude-opus-5-5", max_tokens=4096, system="...",
                       output_config={"effort": "low"}, messages=[...])

# 스트리밍
with client.messages.stream(model="claude-opus-5-5", max_tokens=64000, messages=[...]) as s:
    for t in s.text_stream: print(t, end="")

# 구조화 출력
client.messages.parse(model="claude-opus-5-5", max_tokens=1024, messages=[...],
                      output_format=MyPydanticModel).parsed_output

# 캐싱 (자동)
client.messages.create(..., cache_control={"type": "ephemeral"})

# 토큰 세기
client.messages.count_tokens(model="claude-opus-5-5", messages=[...]).input_tokens

# 배치
client.messages.batches.create(requests=[{"custom_id": "1", "params": {...}}])
```

## D. Claude Code 치트시트

|명령|기능|
|---|---|
|`claude`|대화형 세션 시작|
|`claude -p "질문"`|비대화형(headless) 실행|
|`claude -c`|직전 세션 이어서 하기|
|`/init`|[CLAUDE.md](http://CLAUDE.md) 생성|
|`/clear`|컨텍스트 초기화|
|`/compact`|대화 요약으로 컨텍스트 절약|
|`/mcp`|MCP 연결 상태|
|`Shift+Tab`|권한 모드 / Plan Mode 전환|
|`Esc`|진행 중인 작업 중단|
