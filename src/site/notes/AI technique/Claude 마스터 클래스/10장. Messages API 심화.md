## 10.1 시스템 프롬프트

시스템 프롬프트는 대화 전체에 적용되는 **역할·규칙·맥락**을 정의합니다. 5장의 프로젝트 지침과 같은 역할을 API에서 합니다.

```python
import anthropic

client = anthropic.Anthropic()

SYSTEM = """너는 한화 사내 IT 헬프데스크 어시스턴트야.
- 답변은 한국어 존댓말로, 5단계 이내의 번호 목록으로 안내해.
- 비밀번호 초기화처럼 권한이 필요한 요청은 직접 처리하지 말고 서비스데스크 링크를 안내해.
- 모르는 내용은 추측하지 말고 담당 부서를 안내해."""

response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=2048,
    system=SYSTEM,
    messages=[{"role": "user", "content": "VPN이 자꾸 끊겨요."}],
)
```

## 10.2 멀티턴 대화 — API는 기억하지 않는다

Messages API는 **stateless**입니다. 대화를 이어가려면 이전 메시지 전체를 매번 함께 보내야 합니다.

```python
class ChatSession:
    """간단한 멀티턴 대화 관리자"""

    def __init__(self, system: str):
        self.client = anthropic.Anthropic()
        self.system = system
        self.messages: list[dict] = []

    def send(self, text: str) -> str:
        self.messages.append({"role": "user", "content": text})
        response = self.client.messages.create(
            model="claude-opus-5-5",
            max_tokens=4096,
            system=self.system,
            messages=self.messages,
        )
        # ⭐ 텍스트만이 아니라 content 전체를 저장해야 thinking/tool 블록이 보존됨
        self.messages.append({"role": "assistant", "content": response.content})
        return next((b.text for b in response.content if b.type == "text"), "")

chat = ChatSession(system="너는 친절한 여행 플래너야.")
print(chat.send("12월에 3박 4일로 일본 여행을 가려고 해."))
print(chat.send("온천이 있는 곳으로 바꿔줄래?"))   # 앞의 맥락을 기억함
```

<aside>  
🔍

**심화** — 대화가 매우 길어지는 서비스라면 서버 측 **컴팩션(compaction)** 기능으로 오래된 맥락을 자동 요약하거나, **컨텍스트 편집**으로 오래된 도구 결과를 제거할 수 있습니다. 두 기능 모두 베타이므로 공식 문서를 확인하세요.

</aside>

## 10.3 스트리밍 — 타이핑하듯 보여주기

긴 응답을 끝까지 기다리지 않고 생성되는 대로 보여주면 체감 속도가 크게 개선됩니다. 또한 출력이 길거나 `max_tokens` 가 큰 요청은 HTTP 타임아웃을 피하기 위해 **스트리밍이 사실상 필수**입니다.

Python

```python
with client.messages.stream(
    model="claude-opus-5-5",
    max_tokens=64000,
    messages=[{"role": "user", "content": "우주 탐사를 주제로 단편 소설을 써줘."}],
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)

    final = stream.get_final_message()   # 완성된 메시지 객체

print("\n\n출력 토큰:", final.usage.output_tokens)
```

TypeScript

```tsx
const stream = client.messages.stream({
  model: "claude-opus-5-5",
  max_tokens: 64000,
  messages: [{ role: "user", content: "우주 탐사를 주제로 단편 소설을 써줘." }],
});

stream.on("text", (text) => process.stdout.write(text));

const final = await stream.finalMessage();
console.log("\n\n출력 토큰:", final.usage.output_tokens);
```

## 10.4 이미지와 PDF 입력

`content` 를 문자열 대신 **블록 배열**로 보내면 이미지·문서를 함께 넣을 수 있습니다. 자료를 앞에, 질문을 뒤에 두는 것이 좋습니다.

```python
import base64
from pathlib import Path

def b64(path: str) -> str:
    return base64.standard_b64encode(Path(path).read_bytes()).decode()

response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=4096,
    messages=[{
        "role": "user",
        "content": [
            {   # 이미지
                "type": "image",
                "source": {"type": "base64", "media_type": "image/png", "data": b64("chart.png")},
            },
            {   # PDF 문서
                "type": "document",
                "source": {"type": "base64", "media_type": "application/pdf", "data": b64("report.pdf")},
            },
            {"type": "text", "text": "차트와 보고서의 수치가 일치하는지 확인하고, 불일치 항목을 표로 정리해줘."},
        ],
    }],
)
```

<aside>  
💡

**TIP** — 같은 파일을 여러 번 쓴다면 **Files API**로 한 번 업로드하고 `file_id` 로 참조하세요. 문서 블록에 `"citations": {"enabled": true}` 를 추가하면 답변에 **근거 인용**이 붙습니다.

</aside>

## 10.5 사고(Thinking)와 Effort

최신 Claude 모델은 **적응형 사고(adaptive thinking)**를 사용합니다. 모델이 문제 난이도에 따라 스스로 얼마나 생각할지 정하고, 개발자는 `effort` 로 전체적인 사고 깊이와 토큰 사용량을 조절합니다.

```python
response = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=16000,
    thinking={"type": "adaptive", "display": "summarized"},  # 사고 요약을 보고 싶을 때
    output_config={"effort": "high"},  # low | medium | high | xhigh | max
    messages=[{"role": "user", "content": "이 알고리즘의 시간 복잡도를 증명해줘: ..."}],
)

for block in response.content:
    if block.type == "thinking":
        print("🧠 사고 요약:", block.thinking)
    elif block.type == "text":
        print("💬 답변:", block.text)
```

|effort|적합한 작업|
|---|---|
|`low`|채팅, 분류, 대량·저지연 처리, 서브에이전트|
|`medium`|일반적인 업무, 비용과 품질의 균형|
|`high` / `xhigh`|코딩, 다단계 에이전트 작업, 복잡한 분석|
|`max`|비용보다 정확성이 절대적으로 중요한 난제|

<aside>  
⚠️

**모델별 차이에 주의**

- `~~thinking: {type: "enabled", budget_tokens: N}~~` 는 예전 방식입니다. 최신 모델에서는 오류(400)가 납니다.
- Opus 5.5는 사고를 끌 수 없고, effort 기본값이 `medium` 입니다. 필요한 수준을 명시적으로 지정하세요.
- 최신 모델은 ~~assistant 프리필(prefill)~~ 과 ~~temperature~~ 등의 샘플링 파라미터를 지원하지 않습니다. 형식 제어는 구조화된 출력을 쓰세요.  
    </aside>

## 10.6 구조화된 출력(Structured Outputs)

답변을 프로그램에서 바로 쓰려면 JSON 스키마를 **보장**받아야 합니다. Python SDK는 Pydantic 모델을 그대로 넘길 수 있습니다.

```python
from pydantic import BaseModel

class Ticket(BaseModel):
    category: str          # "계정" | "결제" | "버그" | "기타"
    priority: int          # 1(낮음) ~ 5(긴급)
    summary: str
    needs_human: bool

response = client.messages.parse(
    model="claude-opus-5-5",
    max_tokens=2048,
    messages=[{
        "role": "user",
        "content": "고객 문의를 분류해줘: '결제는 됐는데 프리미엄이 활성화가 안 돼요. 내일 발표에 꼭 필요해요!'",
    }],
    output_format=Ticket,
)

ticket = response.parsed_output        # 검증된 Ticket 인스턴스
print(ticket.category, ticket.priority, ticket.needs_human)
```

## 10.7 오류 처리와 재시도

SDK는 연결 오류, 429(속도 제한), 5xx 오류를 **기본 2회 자동 재시도**합니다. 그래도 실패하면 예외가 발생하므로, **구체적인 예외부터** 잡아 재시도 가능 여부를 구분합니다.

```python
import anthropic

client = anthropic.Anthropic(max_retries=4, timeout=60.0)

try:
    response = client.messages.create(
        model="claude-opus-5-5",
        max_tokens=1024,
        messages=[{"role": "user", "content": "Hello"}],
    )
    if response.stop_reason == "refusal":
        print("안전 정책에 따라 응답이 거절되었습니다.")
    elif response.stop_reason == "max_tokens":
        print("출력이 잘렸습니다. max_tokens를 늘리세요.")
except anthropic.BadRequestError as e:           # 400: 요청 형식 오류 → 재시도 무의미
    print("요청 오류:", e.message)
except anthropic.AuthenticationError:             # 401: API 키 문제
    print("API 키를 확인하세요.")
except anthropic.RateLimitError as e:             # 429: 잠시 후 재시도
    print("속도 제한. retry-after:", e.response.headers.get("retry-after"))
except anthropic.APIStatusError as e:             # 기타 HTTP 오류 (5xx 등)
    print(f"API 오류 {e.status_code}: {e.message}")
except anthropic.APIConnectionError:              # 네트워크 오류
    print("네트워크를 확인하세요.")
```
