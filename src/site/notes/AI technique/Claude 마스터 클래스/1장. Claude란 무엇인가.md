## 1.1 한 문장 정의

> **Claude**는 Anthropic이 개발한 대규모 언어 모델(Large Language Model, LLM) 기반의 AI 어시스턴트로, 글쓰기·분석·코딩·조사·에이전트형 작업을 수행합니다.

Anthropic은 AI 안전성 연구를 핵심 가치로 내세우는 회사입니다. 그래서 Claude는 **도움이 되고(Helpful), 정직하며(Honest), 해롭지 않은(Harmless)** 어시스턴트를 목표로 훈련되었습니다. 이를 흔히 **HHH 원칙**이라고 부릅니다.

## 1.2 LLM은 어떻게 동작하는가

LLM의 본질은 놀랍도록 단순합니다. **"지금까지의 글 다음에 올 가장 그럴듯한 조각(토큰)을 예측"**하는 일을 수억 번 반복합니다. 방대한 텍스트로 사전 학습한 뒤, 사람의 피드백과 Anthropic의 헌법(Constitution) 기반 훈련을 거쳐 유용하고 안전한 대화 상대가 됩니다.

```mermaid
flowchart LR
    A["사용자 입력<br/>(프롬프트)"] --> B["토큰화<br/>Tokenizer"]
    B --> C["신경망이<br/>다음 토큰 예측"]
    C --> D{"끝?"}
    D -- 아니오 --> C
    D -- 예 --> E["응답 출력"]
```

### 토큰(Token)이란?

토큰은 모델이 텍스트를 처리하는 최소 단위입니다. 영어는 대략 단어의 3/4, 한국어는 글자 1~2개 정도가 토큰 하나에 해당합니다. 비용과 길이 제한은 모두 토큰 단위로 계산됩니다.

대략적인 비용 계산식은 다음과 같습니다.

$$  
\text{비용} = \frac{\text{입력 토큰}}{10^6} \times P_{in} + \frac{\text{출력 토큰}}{10^6} \times P_{out}  
$$

여기서 $P_{in}$, $P_{out}$은 백만 토큰당 입력·출력 단가입니다. 출력 단가가 보통 입력보다 약 5배 비싸다는 점을 기억하세요.

### 컨텍스트 윈도우(Context Window)

모델이 한 번에 "볼 수 있는" 텍스트의 최대 길이입니다. 대화 기록, 첨부 파일, 시스템 지시문, Claude의 답변까지 모두 이 안에 들어가야 합니다. 최신 Claude 모델은 **최대 100만(1M) 토큰**의 컨텍스트를 지원합니다. 책 여러 권 분량을 한 번에 넣을 수 있는 규모입니다.

<aside>  
🔍

**심화: 왜 대화가 길어지면 느려지고 비싸질까?**

Claude API는 상태를 저장하지 않는(stateless) 구조입니다. 매 턴마다 이전 대화 전체를 다시 읽기 때문에, 대화가 길어질수록 입력 토큰이 누적됩니다. 주제가 바뀌면 **새 대화를 시작**하는 것이 품질과 속도 면에서 모두 유리합니다.

</aside>

## 1.3 Claude 모델 패밀리

Claude는 성능·속도·비용의 균형에 따라 여러 등급의 모델을 제공합니다. 본 교재 기준일(2026년 11월 8일)의 주요 모델은 다음과 같습니다.

|모델|성격|언제 쓰나요?|API 모델 ID|
|---|---|---|---|
|**Claude Fable**|최고 성능 플래그십|가장 어려운 추론, 장시간 자율 에이전트 작업|`claude-fable-5-1`|
|**Claude Opus**|고성능 범용|복잡한 코딩, 심층 분석, 전문 문서 작성|`claude-opus-5-5`|
|**Claude Sonnet**|성능과 속도의 균형|일상 업무, 대부분의 코딩·에이전트|`claude-sonnet-5-5`|
|**Claude Haiku**|초고속·저비용|분류, 대량 처리, 실시간 응답|`claude-haiku-5-5`|

<aside>  
💡

**TIP — 모델 선택의 황금률**

먼저 성능 좋은 모델로 원하는 결과가 나오는지 확인하고, 그다음에 비용·속도를 위해 단계적으로 내려가세요. 처음부터 작은 모델로 시작하면 "모델의 한계"인지 "프롬프트의 문제"인지 구분하기 어렵습니다.

</aside>

## 1.4 Claude를 만나는 방법

[claude.ai](http://claude.ai) (웹)

브라우저에서 [claude.ai](https://claude.ai)에 접속해 바로 대화합니다. 가장 많은 기능이 제공되는 기본 채널입니다.

데스크톱 앱

macOS·Windows용 앱. 단축키로 언제든 호출하고, 로컬 MCP 서버 연결과 Claude Code 탭을 사용할 수 있습니다.

모바일 앱

iOS·Android 앱. 사진 촬영 후 바로 질문하거나 음성으로 대화할 수 있습니다.

Claude Code

터미널·IDE·데스크톱·웹에서 코드베이스를 직접 읽고 고치는 에이전트형 코딩 도구입니다. (Part 3 — 14장)

Claude API

개발자가 자신의 서비스에 Claude를 통합하는 인터페이스입니다. Amazon Bedrock, Google Cloud, Microsoft Foundry를 통해서도 사용할 수 있습니다. (Part 3 — 10장)

## 1.5 Claude가 잘하는 일 vs. 조심할 점

### ✅ 강점

- 긴 문서 요약·비교·분석
- 글쓰기, 톤 조절, 번역
- 코드 작성·리뷰·디버깅
- 단계적 추론과 수학 풀이
- 도구를 사용한 다단계 에이전트 작업
- 이미지·PDF·차트 이해

### ⚠️ 조심할 점

- **환각(Hallucination)**: 그럴듯하지만 틀린 정보
- 학습 시점 이후 사건은 웹 검색 없이는 모름
- 정확한 수치 계산은 코드 실행 도구가 더 안전
- 법률·의료·금융 조언은 전문가 검토 필수
- 기밀 정보 입력은 조직 정책 확인
